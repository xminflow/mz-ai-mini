## 视觉与交互

保留参考站全屏机器人影像、黑色胶囊导航、暖白背景、淡黄色强调、生活影像、材质选择和产品叙事。按项目要求改用微域生光 / Weelume 品牌，复用现有 Logo、备案组件、MiSans 400/700 和 Poppins 400/600/700 本地字体；标题按语言分别配置比例，具体尺寸见下表。正文 18px、按钮 16px；短视口首屏单独压缩间距并隐藏辅助说明，保留主要行动按钮。卡片的玻璃渐变、模糊、边框和阴影统一由 `theme.css` 中 `--tpl-nb-*` 令牌管理。

PC、iPad、H5 共用一个响应式站点。平板调整为适合的双列，手机单列并补测 320px。所有样式限制在当前模板作用域。动效使用既有 Framer Motion，尊重减少动态效果；减少动态效果时首屏视频不自动播放，仍可主动播放。产品短片提供中英文字幕。

按浏览器实际测量对齐的关键尺寸如下。中文和英文均使用项目既有字体，中文标题按用户复核意见缩小一档，并分别处理换行。

| 项目 | 桌面 | 平板 | 手机 |
| --- | --- | --- | --- |
| 中文主标题、能力区和场景区标题 | 最大 88px | 64px | 44px，320px 窄屏 40px |
| 英文主标题、能力区和场景区标题 | 最大 110px | 72px | 52px，320px 窄屏约 43px |
| 中文 / 英文常规章节标题 | 最大 48px / 60px | 随容器缩放 | 32px / 36px |
| 中英文展开菜单项 | 22px | 22px | 18px |
| 正文 / 按钮 | 18px / 16px | 18px / 16px | 18px / 16px，短屏说明文字 14px |
| 画廊主画面 | 850 × 640px | 最大 729 × 549px | 90% 视口宽 × 300px |
| 相邻画面间距 | 32px | 16px | 8px |

中文主标题行高为 1.3，章节与首页场景卡片标题行高为 1.35，短视口保留同一比例；正文行高为 1.8。行高通过模板主题令牌统一管理。

首页按原站的滚动结构实现：首屏 `100dvh`，移除固定最小、最大高度；首屏在短片段落期间吸附，文字按不同速度向上离场，厨房视频过渡到机器人侧脸，短片标题反向视差、短片在首次进入视口时以弹簧回弹缩放入场，使用无原生进度条的封面，点击后播放本地短片。手机短片段落为 `70dvh`，单独调整标题位移，避免与视频重叠。能力区为七项横向轮播，支持自动播放、暂停、圆点切换和拖拽，首尾相邻画面循环衔接；操作后暂停自动播放。标题逐行出现，首页场景区为桌面三列、手机单列，卡片纵向入场并轻微回正，FAQ 平滑展开。减少动态效果时取消吸附、视差和自动轮播，保留手动切换。

滚动透明度与缩放使用同一个局部进度计算，避免当前 Framer Motion 原生 ScrollTimeline 优化把动画进度按整篇文档计算。标题观察未移动的裁切容器，确保初始位于容器外的文字仍能正常触发入场。系统动效偏好通过 `useSyncExternalStore` 订阅，确保服务端与首次客户端结构一致；减少动态效果的文字通过主题 CSS 直接显示。

菜单支持展开、关闭、Escape、焦点返回与 Tab 循环。品牌链接采用 flex 消除行内基线空隙，语言切换和菜单按钮共用 36px 居中区域，展开与关闭使用同尺寸 SVG。材质可切换四张细节图，FAQ 支持单项展开与收起；价格入口将所选方案传入候补表单，外观支持三个单选项。联系、预约、订阅均采用浏览器约束校验，成功后显示本地演示状态；不发送或保存表单内容，开发日志仅记录表单类型及校验结果。

右下角入口按 Lunera 的现有样式统一：28px Logo 搭配「微域生光」文字、黑色背景、12px 圆角、15px 字号；桌面距右下各 24px，767px 以下距右下各 14px 并尊重安全区域，点击返回 `/templates`。

页面使用模板内的悬浮滚动条：隐藏宿主原生滚动条并取消固定预留槽，6px 圆角滑块覆盖在页面右侧，悬停或操作时加宽至 8px。滚动仍由 document 承担，保持首页吸附和视差；支持拖动、轨道定位、滚轮、触屏及方向键、PageUp/PageDown、Home/End，包含双语无障碍名称与实时位置读数。仅 Nubo 页面启用，离开模板后恢复宿主滚动条。

## 素材与来源

`source-reference.json` 保存页面内容、链接与图片来源，`public/templates/nubo/sources.json` 保存下载清单、尺寸与来源说明。72 张图片转为本地 WebP；首屏使用本地 `home.mp4`，产品短片和能力轮播使用原站挥手片段 `capability.mp4`。原站封面未给出独立完整演示片源，因此产品短片采用现有对应画面片段。项目 Logo 与字体继续复用既有文件，不重新复制。

原站素材的商业许可证尚待确认；当前作为内部复刻演示，正式商用需取得权利人许可或替换为已获许可素材。政策文案针对本模板真实的数据边界重写，产品、团队、评价和价格均标为演示，联系邮箱使用保留域名 `example.com`。

重新同步素材时，在项目 `website/` 目录执行：

```powershell
$env:HTTPS_PROXY='http://192.168.32.1:7078'
py -3 scripts/sync-nubo-assets.py
```

脚本使用环境中已有 Pillow。下载失败会显式报错；已完成的图片可在重新执行时复用。

## 验证与截图

在 `website/` 执行：

```powershell
pnpm exec tsc --noEmit --incremental false
pnpm exec eslint src/features/site-templates/catalog/nubo src/features/site-templates/registry.ts
py -3 -m py_compile scripts/sync-nubo-assets.py
node --check scripts/capture-nubo.mjs
node --check scripts/verify-nubo.mjs
node --check scripts/verify-nubo-motion.mjs
node scripts/capture-nubo.mjs --verify
```

截图与验证使用本机 Chrome、Node 内置 WebSocket 和标准 CDP，复用相同浏览器会话，无需额外 npm 包。`CHROME_PATH` 可指定 Chrome；`NUBO_PREVIEW_URL` 可指定已有开发服务。`--verify-only` 跳过截图，仅验证页面与交互；`--motion-only` 单独执行动效与高度验证；`--scrollbar-only` 单独验收滚动条；`--verify` 包含全部检查。

截图时通过临时样式隐藏滚动条并取消 `scrollbar-gutter: stable` 的预留槽，保留页面真实滚动；每张截图都检查滚动条宽度为 0、预留槽为 `auto`，避免再次生成右侧白边。该样式仅用于截图，不修改站点的滚动行为。

- 截图：12 张，PC 1440×1000、iPad 834×1180、H5 390×844，每端覆盖首页、功能、更新和联系。保存在 `public/templates/nubo/screenshots/`，已登记到元数据和模板画廊。
- 页面矩阵：13 页 × 中英文 × 1440/834/390/320，共 104 次真实浏览器加载，检查单 H1、实际语言、横向溢出、标题裁切、图片解码、MiSans 两档字重、备案和空链接。
