# Hello Monday 参考模板

依据 `docs/template-replication-guide.md` 接入现有整站模板体系；仅增加此模板和注册记录，不新增依赖、后端接口或数据库变更。

## 入口与范围

- 详情：`/templates/hellomonday`
- 中文官网：`/templates/hellomonday/site`
- 英文官网：`/templates/hellomonday/site/en`
- iPad / H5：`/templates/hellomonday/preview?viewport=tablet` / `viewport=mobile`
- 保持 `listed: false`，不自动上架案例市场。

一个响应式官网端，88 个页面、中英文共 176 条内容路由：

| 页面组 | 数量 | 访问方式 |
| --- | --- | --- |
| 首页、作品、服务、关于、故事、产品合作、联系 | 7 | 全站菜单、页脚与页面链接 |
| 求职、实习 | 2 | 全站菜单和页脚 |
| 案例解读 | 70 | 作品网格、筛选、搜索、下一案例 |
| 故事详情 | 7 | 故事列表、下一篇 |
| 隐私说明、使用条款 | 2 | 页脚 |

参考站工作目录的 `bang&olufsen` 在模板中规范化为 `bang-and-olufsen`，符合现有注册表的 kebab-case 约束；来源地址另行保留。

## 设计与交互

- 保留黑白手绘人物、右侧弧形菜单、错落作品网格、服务插画、团队成长照片与深色产品合作页。
- 依据项目文档使用微域生光品牌、本地 MiSans 400 / 700 和 Poppins 400 / 600 / 700；标题按文档采用 28–44px 等令牌，不复制原站巨型衬线字。
- 主题令牌挂载在 `[data-template='hellomonday']`，卡片采用局部玻璃渐变、模糊、边框和阴影。
- 中英文切换保留当前页面、查询参数及锚点；站内导航使用 Next Link。
- 作品分类与查询参数同步，支持搜索和明确的空结果状态。
- 案例图片预览支持前后切换、方向键、Escape 与焦点恢复；团队照片按钮支持现在、青少年和童年切换。
- 标题轮播、视频均可暂停；实时订阅系统动态偏好。减少动态效果时停止自动视频和标题轮播，服务 GIF 与 20 张动态 WebP 改用本地静态帧。
- 联系、求职和实习表单仅做原生浏览器校验，明确显示“尚未发送或保存”；不发请求，不写本地存储，不记录表单个人信息。FAQ 可展开。

## 内容与素材边界

参考站：<https://www.hellomonday.com/>。

`source-data.json` 记录采集结构，`public/templates/hellomonday/sources.json` 记录素材原始地址与权利说明。图片、视频及其静态帧均本地托管；字体复用项目现有本地文件与许可记录。

案例使用对应图片、双语主题简介与设计解读；七篇文章围绕原始主题重新撰写双语手记，**没有复制原站文章全文**。参考影像中的品牌及英文原始画面保留为案例素材。原站长视频、全部三维体验和逐帧时间轴不在模板中逐一重建，案例影像采用精选图片与可放大画廊。

原站公开案例、客户、团队和奖项属于参考工作室，不作为微域生光真实业绩。政策和相关页面均明确标注此边界。参考素材未发现允许商业再分发的公开许可；对外发布或交付前需取得许可或替换素材。

## 验收方式

在 `website` 目录执行：

```powershell
pnpm exec tsc --noEmit
pnpm exec eslint src/features/site-templates/catalog/hellomonday src/features/site-templates/registry.ts
node scripts/verify-hellomonday.mjs
```

浏览器脚本复用 `scripts/lib/browser-cdp.mjs` 与本机 Chrome，通过 `HELLOMONDAY_PREVIEW_URL` 可指定预览地址，默认 `http://localhost:3000`。不安装浏览器或测试依赖。

脚本检查四种真实 CSS 视口：1440×1000、834×1180、390×844、320×844；逐端检查中英文主要页面、代表性文章与案例，核对图片与溢出。另检查菜单、语言、筛选、搜索、表单、FAQ、画廊、成长照片、播放暂停、减少动态效果、客户端路由及设备预览 iframe。

产品页额外检查导航、标题、案例名称、引言和操作链接的实际计算颜色，确保深色内容区域继承白色文字、浅色页脚保持深色文字。主题令牌必须在 `.hm-site` 上同时应用背景与文字颜色，避免子层覆盖变量后仍继承外层已计算的浅色主题文字。

页脚使用源站约 4.88% 的左右留白与 1670px 内容最大宽度，容器居中、各栏文字保持原有对齐；窄屏保留至少 24px 留白。右侧菜单在首屏常显，鼠标设备滚过首屏后收起，右侧边缘悬停或键盘聚焦时显示，悬停位置控制弧形入口的上下位置；触屏设备始终显示入口，减少动态偏好关闭过渡动画。

作品图片通过四边控制点和平滑闭合曲线实现弹性蒙版，鼠标附近的边缘延迟跟随；进入图片深处或移出后释放复原。图片纹理保持不变，不使用噪声位移或固定圆角。现有 Framer Motion 驱动局部路径更新，无新增依赖；只有活动图片执行动画，复原后移除蒙版。触屏及减少动态偏好下保持静态，图片保留案例跳转，不显示右下角悬浮箭头。运行 `node scripts/verify-hellomonday-image-hover.mjs` 可专项检查四边牵引、中心释放、离开复原、动态偏好与触屏行为，并保存交互截图。

全部 176 条内容路径另行真实请求验证，未知页面应返回 404。详情页登记 PC / iPad / H5 各四张真实截图，覆盖首页、服务、故事和联系。机器验收记录位于 `public/templates/hellomonday/screenshots/verification-report.json`。

## 素材维护

`node scripts/sync-hellomonday-assets.mjs` 重新采集素材与页面结构；`--extras` 仅更新团队、服务和首页 / 产品影像。外部来源改变时采集会显式失败，不能把缺失素材当成成功。更新后重新运行浏览器验收以生成静态帧和三端截图。
