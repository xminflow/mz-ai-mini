## 实现边界

以个人、创业者和小团队的财务管理 SaaS 为业务定位，提供收支追踪、预算、报表、账户同步等功能展示。全部 10 页提供中英文，中文品牌为「微域生光」，英文品牌为 Weelume；`lunera` 作为内部目录、路由与代码标识保留。博客正文、作者与日期、FAQ、政策示例、表单校验提示、无障碍标签及示意图均随语言切换。套餐、用户评价、人数和财务数据均为演示数据，美元金额保持原币种。

联系表单包含必填、邮箱格式、空白输入和长度校验。有效输入显示本地校验结果，明确说明消息尚未发送或保存。日志仅记录主题、消息长度与本地校验状态。接收接口、账户连接、支付和应用下载服务尚待实际产品接入。

「下载应用」在桌面导航、手机菜单和首页均为展示按钮，点击仅保留交互动效。「立即开始」仍指向 `data.ts` 中原模板作者的 Contra 购买链接，并在新标签打开。导航、页脚与右下角均使用项目现有微域生光 Logo：浅底使用 `weiyu-logo-web-dark.svg`，深底使用 `weiyu-logo-web-light.svg`。右下角点击同页返回模板目录 `/templates`；原“新模板”卡片及“使用模板”外链已移除。页脚市场链接为“微域生光：模板市场”，标语只保留“让财务管理更从容”；备案信息复用 `TemplateFiling`，固定显示示例ICP备00000000号，不链接真实备案查询页。保留第三方品牌名称与社交链接。联系页使用保留域名 `example.com` 的演示邮箱。Framer 平台水印属于托管平台界面，React 页面中省略该平台水印。

图片和图表使用本地资源，来源记录于 `public/templates/lunera/assets/sources.json`。原始 Geist 素材与许可证保留用于追溯，页面排版已切换为本地 MiSans 与 Poppins。字体来源与许可见 `public/templates/lunera/fonts/README.md`。模板画廊按 PC、iPad、H5 分组，每组四张当前中文页面实际截图，覆盖首页、功能区、博客与联系页，共十二张。

`phone-zh.svg`、`analytics-zh.svg`、`live-chart-zh.svg` 为本项目重新绘制的中文界面示意素材；英文使用对应英文原图。未新增 npm 依赖。

## 双语与排版

参考 `D:/code/yiliart/site` 的 MiSans/Poppins、流式字号和同页语言切换设计。中文使用真实 400/700 字重的 MiSans Unicode 分片；英文与数字使用 Poppins 400/600/700，均本地托管。字体别名与主题令牌限定在模板内，未改动 yiliart 或其他模板的字体。

标题字号通过 `clamp()` 在手机 28px 至桌面 44px 间平滑变化，章节标题为 24–36px，文章标题为 26–36px；正文、说明与元信息分档管理。中文展示标题由 `HeadingText` 按语义短句分行，去掉分行逗号和句末标点；首页首屏两行同样省略标点。正文扩大行高；功能与流程卡片按内容撑开，避免英文长文案被固定高度裁切。导航品牌文字 18px、Logo 24px、下载按钮 13px，收起时导航高度 54px。

中文保持原路径；英文在端路径后添加 `/en`，例如 `/templates/lunera/site/en/blog/5-metrics`。导航始终沿用当前语言；右上角“中 / EN”切换对应页面，保留查询参数与锚点，并用 Next 客户端导航维持同一文档。语言由 URL 明确表示，未引入全站语言重定向或 Cookie 自动推断。模板内容根节点声明 `lang`，根应用的语言和其他模板保持既有配置。

`TemplateSurface.locales` 显式开启语言路由；未声明的端保留原页面解析方式。`localizedNames`、`localizedTitles` 分别管理站点与页面标题；`messages.ts` 管理带类型约束的 UI 译文，`content.ts` 管理英文内容，文章按 slug 关联共享素材。

## 结构与动效

所有卡片共用模板内的玻璃材质令牌：半透明白色渐变、20px 背景模糊、白色高光描边与蓝灰柔影。章节背景提供蓝紫色径向柔光并向上下淡出，避免白底上玻璃效果缺乏层次。覆盖首屏浮卡、功能、集成图标、流程、价格、评价、统计、FAQ、博客、联系表单与联系方式；推荐方案为浅蓝玻璃，重点评价为深蓝玻璃。流程卡片提高底色不透明度，避免 sticky 叠层时文字互相透出。材质与布局由现有 CSS 主题统一管理，交互动效继续使用 Framer Motion。

834px 平板视口使用双列功能、博客和联系方式卡片，价格为两列加末卡居中；FAQ 与流程区顺序纵向排列。767px 以下价格和联系方式改为单列，表单按钮全宽，流程卡取消 sticky 叠层；500px 以下功能、博客单列，统计区两列加末项跨列。手机首屏缩小应用示意图与留白，390×844 下主操作可见。保留安全区间距与折叠菜单。本次覆盖 PC、iPad 与 H5，小程序未纳入交付。

- `meta.ts`：十个页面的注册信息；内部链接由 `basePath` 拼接。
- `data.ts`：内容、文章、FAQ、套餐与外链。
- `content.ts`、`messages.ts`：双语正文与界面文本。
- `components/`：公共导航、页脚、卡片、FAQ、文章和法律页布局。
- `pages/`：按页面加载的入口。
- `theme.css`：限定在 `[data-template='lunera']` 内的设计令牌和响应式样式。

使用项目已有的 `framer-motion`，没有新增依赖。动效包括导航与首屏入场、滚动显现、手机视差、信息卡悬浮、集成图标浮动、品牌条循环、按钮反馈、评价轮播、数字增长、菜单与 FAQ 展开。流程卡片通过 sticky 保持叠层布局，入场由 Motion 控制。

站内导航、页脚、文章和条款链接统一使用 Next.js `Link`；动效按钮与文章卡片通过 `motion.create(Link)` 保留交互反馈。避免普通锚链接跨页时重新加载整个文档产生白屏。跨页锚点由 Next 路由定位，外链继续使用独立标签页。

统一尊重 `prefers-reduced-motion`：关闭视差、循环位移与入场位移，菜单和 FAQ 采用即时状态切换。评价轮播支持按钮、方向键及触摸滑动；移动菜单支持 Escape 关闭。
