## 五、写作规范（继承全书约定）

1. **五段式结构**：现象 → 反共识结论 → 推导 → 案例 → 工具  
2. **案例必须真实可查**：全部来自素材原文，不编造数字  
3. **每节至少一个工具**：可填表格 / 检查清单 / 决策树，含示例行 + 空白行  
4. **番外卷定位**：不重复正卷方法论，只讲"该行业如何把前面的方法用起来"  
5. **阅读四问框架**（X.0 导读提出，各节贯穿）：他是谁 / 给谁说话 / 钩子是什么 / 变现链路是什么  
6. **风格**：简体中文，不用"宝子们""家人们"，不用"颠覆认知"等空洞词

## 六、UI 组件

沿用正卷现有组件（全部在 page.tsx 内定义，不抽共享组件）：

- `Chapter` — 章节容器（含 id、no、tag、title、lead、first 等 props）
- `SubHead` — 二级标题
- `PullQuote` — 拉出金句
- `Insight` — 核心主张高亮块
- `CaseBlock` — 案例块（含 title）
- `ToolCard` — 工具卡（含 tag、title、desc）
- `Table` — 可填表格（含 head、rows、fillRows）
- `Strong` — 行内加粗
- `NumberedFalseList` — 编号伪命题列表（X.0 导读可用）
