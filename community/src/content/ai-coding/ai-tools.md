你大概听过这样的说法：现在不用懂代码，也能让 AI 帮你把脑子里的想法，做成一个能用的小工具、小网站。这是真的。

但很多人卡在了第一步——「到底该用哪个 AI 工具？」名字一大堆：Claude Code、Codex、Kimi、GLM……听着都很厉害，却不知道它们有什么区别、自己该用哪个、要花多少钱、在国内能不能用上。光是选工具，就劝退了一大批人。

这一节不绕弯子，只帮你解决三件事：看懂这些工具到底是什么、按你的情况选对一个、然后手把手把它装上，跑出你的第一个结果。

## 一、先搞懂一件事：这些工具其实分「两层」

在挑选之前，先破除一个最常见的误解。很多人把上面那些名字当成「同一类东西在比谁更强」，其实它们分属两层，搞混了就会越看越乱。

打个比方。你去理发店，里面有两样东西：一个是你坐的「工位」——镜子、椅子、工具都在手边，你在这儿跟师傅说想要什么发型；另一个是真正动手的「理发师傅」。AI 编程也是这样分成两层：

- 「壳」＝你跟 AI 打交道的工作台。你在这里打字说需求、看它干活、让它修改。代表：Claude Code、Codex、Kimi 的命令行工具。
- 「大脑」＝真正读懂你的话、动手写代码的那个 AI 模型。代表：Claude、GPT、Kimi、GLM。

> [!NOTE]
> 关键就在这里：壳和大脑是可以拆开搭配的。也就是说，你完全可以用一个「最好用的工作台」，配上「另一家的师傅」。记住这一点，下面很多看似矛盾的选择就都说得通了——这也是为什么人在国内，照样能用上口碑最好的那个工作台。

## 二、认识一下这几位「选手」

知道了分两层，我们就一个个来认识它们。这里不排名、不评谁是第一，只讲清「它是谁、用它有什么门槛」，方便你后面对号入座。

先看两位常被提到的国外工具：

- Claude Code —— 目前公认最成熟、最顺手的「工作台（壳）」，默认配的是 Claude 这个大脑，写代码很强。
- Codex —— OpenAI 出的同类工作台，背后配 GPT 大脑，用法和风格类似。

> [!WARNING]
> 它们都很强，但对国内用户有两个现实门槛要先说清楚：一是需要「科学上网」才能访问，二是付费基本要用海外的支付方式（比如海外信用卡）。这两点我们不展开怎么操作，你只需要知道：能搞定、又愿意折腾，它们体验最顺；搞不定也完全没关系，往下看。

再看两位国内的：

- Kimi（出自月之暗面）、GLM（出自智谱）—— 它们主要扮演「大脑」，也就是真正写代码的那一层。这几年进步很快，写代码的能力已经能对标国外主流模型。
- 它们最香的地方：不用科学上网、用人民币就能付费、而且便宜（入门套餐低至几十元一个月，具体价格以官方为准）。

> [!NOTE]
> 更妙的是，国产大脑提供了「兼容接口」——说人话就是：它们能直接塞进 Claude Code 这个最好用的工作台里用。于是你既享受了好工作台，又用上了便宜、免梯子的国产大脑。

## 三、那我到底该选哪个？对号入座就行

不用纠结谁更强，按你自己的真实情况对号入座，最省事。看看你属于下面哪一种人：

- 能科学上网、也愿意搞定海外支付，想要最顺的体验 → 直接用 Claude Code 原生（自带 Claude 大脑）。
- 不想折腾科学上网和海外支付，只想踏实开始 → 用 Claude Code 这个工作台，配上国产大脑（GLM 或 Kimi）。免梯子、人民币付费。这条对零基础最省心，本节就手把手带你走它。
- 预算很敏感、想先花最少的钱试试水 → 从国产入门套餐起步（几十元一个月），跑顺了再考虑要不要升级。

> [!NOTE]
> 一句实在话：国产方案最省心，日常想做的东西完全够用；只有在个别特别复杂的任务上，顶尖的国外模型可能还略有优势。先用顺手、把东西做出来，比一开始就纠结「哪个最强」重要得多。

## 四、动手：把它装上，跑出第一个结果

我们就走最省心的那条路：Claude Code（工作台）+ 国产大脑（GLM 或 Kimi）。免梯子、人民币付费，用的还是口碑最好的工作台。下面每一步，我都会告诉你「会看到什么」和「卡住了怎么办」。

开始前，先认识一个词：终端。它就是一个让你用打字的方式给电脑下命令的「小黑框」（Windows 上叫「终端」或「PowerShell」，Mac 上叫「终端 / Terminal」）。平时我们用鼠标点，终端是用文字说——别怕，你只要照着把命令贴进去、按回车就行。

第 1 步：装好「运行环境」。Claude Code 要靠一个叫 Node 的基础软件才能跑，就像 App 得先有手机系统。去 Node 官网下载安装包，一路「下一步」装完即可（认准官网，别从来路不明的地方下）。装完后，在终端输入下面这行，能显示出一串版本号，就说明装好了。

```bash
node -v
```

卡住了怎么办：如果提示「不是内部或外部命令」，多半是没装好，或者需要把终端关掉重开一次再试。

第 2 步：装 Claude Code。在终端贴入下面这行命令、按回车，等它自己下载安装：

```bash
npm install -g @anthropic-ai/claude-code
```

你会看到：终端滚动出一堆文字，最后停下来、没有报错，就装好了。卡住了怎么办：如果下载很慢或失败，通常是网络问题，多试一两次；如果是公司网络受限，换个网络环境再来。

第 3 步：填两样东西——「钥匙」和「地址」。这一步，是让 Claude Code 这个工作台去用国产大脑。你需要先在国产大脑的官网（GLM 或 Kimi）开通它们的「编程套餐」，拿到两样东西：一把「钥匙」（官方叫 API Key，相当于你的专属通行证，别外传给任何人）和一个「接入地址」。然后在终端里，把它们告诉 Claude Code（下面是 Windows PowerShell 的写法，Mac 上把 $env: 换成 export 即可，具体变量名与地址以你开通那家的官方文档为准）：

```powershell
# 把引号里的内容换成官方给你的钥匙和地址
$env:ANTHROPIC_AUTH_TOKEN="你的钥匙"
$env:ANTHROPIC_BASE_URL="官方给的接入地址"
```

你会看到：贴完按回车，没有任何报错，就算设好了（它不会有成功提示，这很正常）。卡住了怎么办：变量名和地址一定要照官方文档一字不差地填；这一块各家偶有差异，以你开通那家的官方说明为准。

第 4 步：让它干第一件事。在终端输入下面这个词、回车，启动工作台：

```bash
claude
```

然后用大白话对它说一句需求，比如：「帮我做一个网页，在正中间显示一行字：你好，世界」。你会看到：它会思考几秒，然后开始建文件、写代码，整个过程都显示在屏幕上。

第 5 步：看到你的第一个结果。按它的提示把生成的网页打开（它通常会告诉你怎么看），你就能在浏览器里看到那行字。恭喜——你已经完整走通了「描述 → 生成 → 看到结果」这一圈，这正是 AI 编程最核心的一步。

> [!TIP]
> 第一次面对终端、命令、报错，觉得陌生甚至有点慌，太正常了——每个人都是这么过来的。卡住的时候，把报错的原话复制下来，回头你甚至可以直接问 AI：「这个报错是什么意思、该怎么办」。

如果你属于前面说的「能科学上网 + 能海外支付」那一类人，可以跳过第 3 步填钥匙，装好后直接登录官方账号、用 Claude Code 原生即可；想试 Codex、或各家自带的命令行工具，思路完全一样，照它们官网的「快速开始」走就行。

到这儿，你已经选好了工具、装上了、还跑出了第一个结果。下一部分，我们再回过头，把「开发世界」整体快速过一遍（前端、后端、数据库到底各是什么），以及怎么把 AI 编程变成一套你自己顺手的工作流。
