# methodology-primer.md — 微域生光 Playbook 方法论术语库

本文件是 Claude 在 Step 2 写 `script.json` 之前必须读取的方法论参考。

短视频拆解的本质，是**把博主做对的某一件事，映射到 微域生光 Playbook 9 篇中的某一条方法论上**，让观众听到的不只是"这个博主做了什么"，而是"这个动作命中了哪条方法论"。

## 强绑定铁律（违反必须重写）

1. 每个 `script.json` 必须**显式说出**至少 1 个 Playbook 关键词（精确字符串匹配），出现位置应在 `bullets` 或 `compare` slide 的 `narration` 中，不可只放在 cover 或 cta。
2. 该关键词必须出现在**口播 narration** 里（视觉看到、耳朵听不到 = 无效）。
3. 一条视频建议主线支柱 1-2 个，**不贪多**——4-5 张幻灯片塞不下 3 个支柱。
4. 严禁分析博主短板（信息不足以支撑判断）。映射只做"做对的事 → 命中哪条方法论 → 现在怎么放大"。

## 1. 九篇核心术语清单（关键词以加粗标出，是 narration 校验的精确匹配项）

### Foundations · 底层逻辑

判断这个博主能跑出来，是否踩中"内容稀缺 × 效率红利 × 信任纽带"。

可识别关键词：
- **收入=流量×变现** / **流量×变现**
- **流量经济** / **粉丝经济** / **品牌经济**
- **信任前置**
- **效率是风口本质** / **效率红利**

### Positioning · 定位

判断这个博主是否把"一类需求"画上了等号、是否有清晰的视觉锤与文字钉。

可识别关键词：
- **画等号**
- **内容定位三原则**（多维 · 原生 · 高频）
- **痛点+方案** / **痛点方案**
- **视觉锤** / **文字钉**
- **商业定位四阶梯**

### Topics · 选题

判断这个博主选题是否成体系、是否踩中爆款元素、是否做了系列化。

可识别关键词：
- **选题五方向**（人/事/物/趣/情）
- **八大爆款元素**
- **情绪波点**
- **选题系列化**（定量 + 变量）
- **跨领域借鉴**

### Scripts · 文案与脚本

判断这个博主用的是哪一类脚本骨架。

可识别关键词：
- **四型脚本**（聊观点 / 教知识 / 讲故事 / 晒过程）
- **聊观点脚本** / **教知识脚本** / **讲故事脚本** / **晒过程脚本**

### Craft · 拍摄与剪辑

判断这个博主的呈现是否做到表现力优先。

可识别关键词：
- **三分拍七分剪**
- **表现力优先**

### Growth · 增长与投放

判断这个博主是否吃到了算法的标签机制 / 完播率 / 赛马 / 铁粉。

可识别关键词：
- **三层标签** / **三层标签机制**
- **完播** / **完播率**
- **赛马机制**
- **铁粉机制**
- **目的垂直** / **手段多维**

### Monetization · 变现

判断这个博主的变现是否离钱近、路径短，是 2C 还是 2B。

可识别关键词：
- **变现四原则**
- **离钱近** / **路径短**
- **2C2B**
- **4P**
- **客户分层** / **价值排序** / **变现链路**

### Industry · 番外行业卷

如果博主主线属于 5 大行业之一，可以引用对应打法做注脚。

可识别关键词：
- **本地实体** / **专业人士** / **教育培训** / **零售** / **数字产品**

## 2. 博主动作 → 支柱映射规则

判断流程（按顺序逐条试，命中一条即停，最多挑 2 个支柱）：

| 博主的核心成长动作偏向 | 主线支柱（先选 1 个） | 可补充的副线支柱 |
|---|---|---|
| 收窄品类 / 锁人群 / 固定人设 | `positioning`（画等号 + 内容定位三原则） | `foundations`（粉丝经济 / 信任前置） |
| 选题成体系 / 持续踩爆款元素 | `topics`（选题五方向 / 八大爆款元素） | `scripts`（四型脚本） |
| 用某一种脚本骨架反复打 | `scripts`（四型脚本） | `topics` |
| 完播 / 停留 / 互动数据稳定高 | `growth`（三层标签 / 完播 / 赛马机制） | `topics` |
| 持续涨粉、铁粉密度高 | `growth`（铁粉机制 / 目的垂直） | `positioning` |
| 把流量切到 2C 课程 / 训练营 / 知识付费 | `monetization`（2C2B / 变现四原则） | `positioning` |
| 把流量切到 2B 品牌合作 / 探店 / 接单 | `monetization`（4P / 客户分层） | `industry` |
| 处于 5 大行业之一且打法有共性 | `industry`（对应行业） | `monetization` |
| 跨平台 / 跨账号矩阵化运营 | `foundations`（效率红利） | `growth`（目的垂直·手段多维） |

注意：上表只是引导，**不允许只为"凑支柱"硬贴标签**。如果某博主的动作映射不上任何一条，说明信息不足，应跳过 compare 改用第二张 bullets。

## 3. 脚本句式范例（如何把术语融进 ≤18 字口播）

不要硬贴标签，要把术语**自然嵌入口播**。

| 方法论关键词 | narration 句式（≤18 字） |
|---|---|
| 画等号 | "他把上班族减脂这件事，画上了等号。" |
| 内容定位三原则 | "他踩中了内容定位三原则。" |

| 文字钉 | "这句话，是他的文字钉。" |
| 选题五方向 | "他的选题，全押在'人'和'情'两个方向上。" |
| 八大爆款元素 | "每条视频都踩了反差感这一个爆款元素。" |
| 选题系列化 | "他把这件事做成了选题系列化。" |
| 四型脚本 | "他用的是聊观点脚本，不是教知识脚本。" |
| 三分拍七分剪 | "他信三分拍七分剪。" |
| 三层标签 | "算法给他的标签，已经焊死在减脂这一格。" |
| 完播 | "完播率高，是他算法稳定的真正原因。" |
| 赛马机制 | "他用赛马机制，在跑同一个选题的 N 个版本。" |
| 铁粉机制 | "他的铁粉机制，跑出来了。" |

## 4. 一条视频的方法论组装范式

围绕 1-2 个主线支柱组装 4-5 张幻灯片：

```
cover    博主名 + 一句话定位（不直接说方法论）
hook     一个数字 / 一个反差 / 一个疑问（黄金 3 秒）
bullets  3-4 条动作，至少 1 条与主线支柱对应；narration 必须出现至少 1 个方法论关键词
compare  做对的事 → 怎么放大（与同一主线支柱呼应；或省略）
cta      "更多博主拆解，关注 微域生光，我们研究真实的博主增长。"
```

bullets 与 compare 至少有一处的 narration 显式使用主线支柱关键词，二者不允许同时缺失。

## 5. 范例：主线支柱 = positioning + monetization

```
cover    narration: "今天拆一个上班族减脂博主。他不是教练，粉丝却比很多教练多。"
hook     hook_big_text: "128 万"，hook_sub_text: "粉丝里 80% 是上班族。"
         narration: "他不是赢在量，他赢在'谁'。"
bullets  narration: "他干对了三件事。他把上班族减脂画上了等号——这是他的画等号。
                    他的视觉锤就是自己——一个普通上班族。第三，他的变现，离钱近。"
         bullets: ["人设 = 普通上班族（视觉锤）",
                   "需求 = 上班族减脂（画等号）",
                   "变现 = 训练营 + 知识付费（离钱近）"]
compare  compare_before: "早期就抓住了'上班族'这一类人"
         compare_after: "现在他把这件事做成了 2C 训练营 + 2B 品牌合作"
         narration: "早期他就抓住了'上班族'这一类人。现在，他把这件事做成了 2C2B 两条变现。"
cta      narration: "更多博主拆解，关注 微域生光，我们研究真实的博主增长。"
```

校验：
- "画等号"、"视觉锤"、"离钱近"、"2C2B" 均在 narration 中精确出现 ✓
- 全程未提及短板 ✓
- 主线支柱 = positioning（画等号 / 视觉锤），副线 = monetization（离钱近 / 2C2B） ✓

## 6. 主线支柱决策检查

写 script.json 之前必须在心里回答以下 4 个问题，任一回答不上来要再读一遍 outline.chapters：

1. 这个博主**做对的核心一件事**是什么？（一句话，≤25 字）
2. 这件事**对应 Playbook 哪一篇**？（指定 1-2 个）
3. 我可以在 narration 里**精确说出哪几个关键词**？（至少 1 个）
4. 他近期是**怎么把这件事放大**的？（用于 compare 的 after；如果想不出，就用 bullets 顶替 compare）

回答完这 4 个问题，再开始 Write `script.json`。
