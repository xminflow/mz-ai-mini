>
> 怎么读：只想知道「我该用哪个」的同学，直接看 [总览对比表](#一张表看懂主流工具) 和 [选型建议](#选型建议按人群和场景)；想了解能力差异和基准的，往下看 [权威基准怎么看](#权威基准怎么看swe-bench)。

## 先认清现状：AI 编程已是主流，但远没到「全自动」

先用权威调查把背景说清楚，避免被营销话术带偏。

- **几乎人人在用**：JetBrains 2026 年 1 月对 1 万多名专业开发者的调查显示，**90%** 的开发者日常在工作中使用至少一种 AI 工具，**74%** 用上了专门的 AI 开发者工具（编码助手 / AI 编辑器 / 智能体，不含纯聊天机器人）。
- **格局在洗牌**：同一调查里，GitHub Copilot 仍以 **29%** 的工作采用率（76% 知名度）排第一，但增长已经停滞；**Cursor 和 Claude Code 并列第二（各 18%）**。在偏资深、创业团队为主的 Pragmatic Engineer 调查（906 人）里，2025 年 5 月才发布的 **Claude Code 在 8 个月内冲到「最常用」与「最受喜爱」双第一**（最受喜爱：Claude Code 46% > Cursor 19% > Copilot 9%）。
- **但别神化它**：Stack Overflow 2025 年开发者调查（4.9 万份回复、166 国）显示，开发者对 AI 的信任不升反降——**46% 的人主动不信任** AI 输出的准确性，只有 33% 信任；对准确性的正面信任从此前的约 40% 降到 29%。而且 **52% 的开发者要么不用智能体、要么只用更简单的 AI 功能**，每天用「自主智能体」的仅 14.1%。

**一句话**：工具很强、值得学，但它现在更像「能力极强但需要你盯着的实习生」，不是「按一下就交付」的黑盒。这也正是要「学架构、学思维」而不是只学「点哪个按钮」的原因。

## 三种工具形态，先分清再选

市面工具五花八门，但按「自主程度」可归为三类，能力与价格基本沿这条线递增：

1. **补全 / 对话型**：在编辑器里给你灰色补全建议、侧边栏聊天问答。代表：GitHub Copilot（经典形态）、各家国产灵码类插件。门槛最低，适合入门。
2. **IDE 内智能体（多文件 Agent）**：能读整个项目、跨多个文件改代码、自己跑命令看结果。代表：Cursor、Windsurf、Copilot/Codex 的 Agent 模式。这是目前「生产力跃升」的主力形态。
3. **终端 / 云端自主智能体**：在命令行或云端跑，能长链路自己干活（读代码→改→测→修）。代表：Claude Code、OpenAI Codex、Devin。最强也最「费 token」，需要你会给指令、会验收。

> 入门建议：从第 1 类用起，理解「描述需求 → 看产出 → 读报错 → 再交流」这个闭环，再逐步过渡到第 2、3 类。

## 国外主流工具逐个看

### GitHub Copilot —— 普及度第一的「老大哥」

- **形态与能力**：行内补全、聊天、多文件编辑（Copilot Edits）、Agent 模式都有；但不同编辑器功能不完全对等（如 Vim 没有聊天 / Agent）。
- **集成**：VS Code、JetBrains、Visual Studio、Vim 等，扩展生态最成熟。
- **价格**：**免费档**（每月 2000 次补全 + 50 次聊天请求）、**Pro $10/月**、**Pro+ $39/月**。注意：自 **2026 年 6 月 1 日起转向基于用量的 AI Credits 计费**，上述价格为 2025–2026 年初口径。
- **适合谁**：想低成本上手、用主流 IDE、追求稳定生态的个人和团队。

### Cursor —— AI 原生编辑器的代表

- **形态与能力**：基于 VS Code 的 AI 原生编辑器，强在「读整个项目做多文件修改」的 Agent 体验和 Tab 智能补全。
- **价格**：**Hobby（免费，无需信用卡，有限 Agent 请求 + 有限 Tab 补全）**、**Pro 从 $20/月起**，上面还有 Pro+ / Ultra 更高档，**Teams $40/用户·月**。
- **计费方式变了**：自 **2025 年 6 月**起，Pro 从「按请求次数」改为「**含 $20 用量额度**」——Tab 和 Auto 模式模型无限用，另含每月 $20 的前沿模型用量（按 API 价计），可按成本加购。
- **避坑**：网上流传的「Pro $16 / Pro+ $48」不准确——**$16 是年付折后等效价**，「Pro+ $48」系误传，请以官网为准。
- **适合谁**：愿意换一个 AI 原生编辑器、重度使用多文件 Agent 的开发者。

### Claude Code —— 资深开发者圈的「黑马」

- **形态与能力**：终端 / 命令行里的自主编码智能体（也有编辑器集成），擅长长链路任务和大型代码库；在资深开发者调查里口碑第一。
- **价格**：**含在 Claude Pro 订阅里**（$20/月，或年付合 $17/月、预付 $200）；更高用量走 **Claude Max（从 $100/月起，5 倍 / 20 倍用量）**。**免费档（$0）能聊天和生成代码，但不含 Claude Code**。
- **适合谁**：能写清楚需求、会验收、追求自动化程度的中高阶开发者。

### OpenAI Codex —— 不单独收费，跟着 ChatGPT 走

- **形态与能力**：编码智能体，提供 **Chat / Agent / Agent(Full Access)** 三档自主度（从纯对话到几乎全自主）。
- **集成**：VS Code、Cursor、Windsurf、JetBrains 系（IntelliJ/PyCharm/WebStorm 等），覆盖 macOS/Windows/Linux。
- **价格**：**不单独计费，内含于各级 ChatGPT 订阅**（Free 起，**Plus $20/月**，**Pro 从 $100/月起**，更高速率上限）。**2026 年 4 月起改为基于 token 的 Credits 计费**；官方称单个任务约消耗 5–45 Credits、平均约 $100–$200/开发者·月（波动很大，*此为中等置信度数据*）。
- **适合谁**：本来就用 ChatGPT 订阅、想顺手用上编码智能体的人。

### Windsurf —— 已并入 Devin

- **现状**：Windsurf 已被 Cognition 收购并入 **Devin**，`windsurf.com` 跳转到 `devin.ai`。
- **价格**：**Free $0**（轻量 agent 额度、有限模型、无限内联编辑与 Tab 补全）、**Pro $20/月**（OpenAI/Claude/Gemini 前沿模型、SWE 1.6、Devin Cloud 云端 agent）。
- **适合谁**：想要「编辑器 + 云端 agent」一体化的团队。

## 国内主流工具逐个看

> 说明：国产工具更新和改名都很频繁，下面**带具体价格的为已查到官方一手来源**；标注「*官方数据未核实*」的，是本次没拿到官方页确认、不臆造数字的项，使用前请到官网确认。

### 通义灵码（阿里）→ 现名 Qoder CN

- **重要变化**：**2026 年 5 月 20 日更名 Qoder CN 并改为 Credits 计费**。
- **价格**：**社区版免费**（有限智能补全 + 有限额度的 Chat 对话，含 300 Credits）；**个人专业版 Pro 59 元/月**（2000 Credits）；**企业标准版 99 元/席位·月**（3000 Credits）；**企业 VPC 版 199 元/席位·月**（3000 Credits，50 席起售）。
- **底层模型 / IDE**：通常与阿里 Qwen（通义千问）代码模型绑定，但*具体型号与支持 IDE 官方数据本次未单独核实*。
- **适合谁**：国内团队、看重中文支持与本地可达性、想要免费起步的个人。

### 百度文心快码 Comate

- **价格**：**个人标准版完全免费**（含智能代码补全），智能体（Agent）功能按「请求券」计费；**企业专业版 ¥358/月、¥1074/季、¥3998/年**（每人每月赠 ¥72 请求券），**企业旗舰版 ¥2500/年**（每人每月赠 ¥283 请求券）。*企业版价格为单一官方来源，置信度中等，易变*。
- **适合谁**：想要「补全完全免费」、国内开箱即用的个人和企业。

### 腾讯 CodeBuddy

- **价格（官方定价页口径）**：**个人 Pro 促销 $9.95/月**（原价 $19.90）或 $119.40/年，含 1000 credits/月；**团队版 $40/席位·月**或 $480/年。
- **注意**：该官方定价页**未列免费档**，也**未点名任何底层大模型**（仅写「所有高级模型」）。坊间（InfoQ/CSDN）称国内版免费、用混元 + DeepSeek-V3，国际版用 Claude/Gemini/GPT——*但不在官方定价页范围内，未核实*。
- **适合谁**：腾讯云生态用户、需要团队协作的开发者。

### 字节 Trae（含豆包 MarsCode）

- **价格（国际版）**：**Lite $3/月、Pro $10/月**（Pro 含 7 天试用）；**2026 年 2 月 24 日起改为基于 token 的计费**（*此为中等置信度*）。
- **注意**：国内外版本差异、可选底层模型、豆包 MarsCode 的具体定价与模型，*本次未拿到官方确认*。
- **适合谁**：预算敏感、想低价用上 AI 编辑器的个人。

### 智谱 CodeGeeX / 讯飞 iFlyCode 等

这几款（CodeGeeX 基于智谱 GLM、iFlyCode 基于讯飞星火）是国内常见选项，但**本次研究未拿到可引用的官方定价 / 模型一手数据**，为避免误导这里不列具体数字。需要时请直接查各自官网。

## 权威基准怎么看（SWE-bench）

工具的「聪明程度」很大程度取决于它背后接的大模型。目前最被认可的公开基准是 **SWE-bench**——让模型去解真实开源项目里的 GitHub issue。

- **SWE-bench Verified**：与 OpenAI 合作、人工筛选出的 **500 道**高质量子集（取自 12 个 Python 仓库），是 2024 年至今的「标准考卷」。
- **SWE-Bench Pro**（Scale AI）：更难、**抗数据污染**的升级版，共 **1865 道**、41 个专业仓库（Public 731 / Held-out 858 / 商业集 276），专门解决「题目太简单、被模型背过了」的问题。

在 Scale AI **标准化脚手架（SEAL）** 的 SWE-Bench Pro 公开榜（731 题、Pass@1，分数日期 2026-06-09）上：

| 排名 | 模型 | 得分 |
| --- | --- | --- |
| 1 | GPT-5.4 (xHigh) | 59.1% |
| 2 | Muse Spark | 55.0% |
| 3 | Claude Opus 4.6 (thinking) | 51.9% |
| 4 | Gemini 3.1 Pro (thinking) | 46.1% |

**看榜的两个关键提醒（很重要）：**

1. **名次差距没有看上去那么大**：前三名的置信区间约 ±3.6，互相重叠，统计意义上「咬得很紧」，不能简单说「第一就碾压第三」。
2. **不同口径不能直接比**：上面是 SEAL 标准化脚手架的成绩；厂商用自家脚手架报的分数（例如 Claude Opus 4.8 在自家口径报到 69.2%）**和这个榜不是一把尺子，不能混在一起比**。看分数一定要看「同一脚手架 / 同一数据集」。

> 给入门同学的实操结论：**别纠结榜单零点几个百分点的差距**。主流前沿模型（GPT-5.x、Claude Opus 4.x、Gemini 3.x、以及国产 Qwen3-Coder 等）能力都在第一梯队，真正拉开差距的是「你会不会用」。

## 国产模型也已是第一梯队

国产开源代码模型的代表是 **Qwen3-Coder（阿里通义千问）**：**480B 总参 / 35B 激活**的 MoE 架构（160 个专家、激活 8 个），**原生 256K 上下文**（经 YaRN 可扩到 1M），在 **7.5 万亿 token**（其中 70% 是代码）上训练，2025 年 7 月发布。这意味着国内工具在底层模型上不再是「将就」，中文场景与本地可达性反而是优势。

## 选型建议（按人群和场景）

- **零基础 / 学生 / 预算紧**：先用免费档起步——GitHub Copilot 免费档、Cursor Hobby、通义灵码社区版、文心快码（补全完全免费）。把「描述需求→看产出→读报错」的闭环练熟，再考虑付费。
- **国内开发、看重中文与免代理可达**：优先**通义灵码 / Qoder CN、文心快码 Comate、腾讯 CodeBuddy、字节 Trae** 等国产工具，本地化和访问更省心。
- **想要最强的「自主干活」体验**：上 **Claude Code** 或 **OpenAI Codex**（终端/云端自主 agent），但要有「会给指令、会验收、token 有成本」的心理准备。
- **离不开多文件重构、喜欢 AI 原生编辑器**：选 **Cursor** 或 **Windsurf（Devin）**。
- **企业 / 团队**：看重生态与合规——国外 Copilot Business、Cursor Teams；国内 Qoder CN 企业版、文心快码企业版、CodeBuddy 团队版，按数据安全与私有化需求（如 VPC 版）选。

> 终极建议：**工具会一直变、价格会一直调，但「怎么把需求讲清楚、怎么验收 AI 产出、怎么搭自己的工作流」这套思维是通用的、不会过时的**。先投资思维，再追工具。
