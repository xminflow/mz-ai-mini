# Ilse Moreno 主站适配

通用源码主维护于独立工程 `D:/code/code-tpl/ilse-moreno-template`，本目录只提供注册与品牌、Logo、市场入口和示例备案注入。

本地开发使用 `pnpm template:local --id ilse-moreno D:/code/code-tpl/ilse-moreno-template`。生产必须使用固定 vendor 包、模板锁及包管理器生成的依赖锁，不能直接读取本机源码。Git 及 ZIP 的公开交付状态见主站 `docs/ilse-moreno-template-delivery.md`，缺少真实公开地址时不填写占位 Git 地址。
