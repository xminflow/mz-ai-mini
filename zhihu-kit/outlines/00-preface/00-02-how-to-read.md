## 结构

### 1. 钩子（约 250 字）
- 反共识断言：这个专栏的设计前提是被翻烂、被画满、被抄进笔记
- 读完不动手 = 没读
- 开始前先确认两件事：是不是写给你的、你打算怎么读

### 2. 真实片段（约 350 字，1 段）
- 38 岁市场总监，To B 营销背景，开副业号
- 不按顺序读，跳到「写不出选题」「文案留不住人」两段
- 三个月跑通第一笔个人 IP 咨询变现（3000 块）
- 主张："找对入口比从头读完更重要"

### 3. 主体（约 2000 字）

#### 3.1 五类读者（约 800 字 / 五类各 130-160 字）
- 实体生意老板（餐饮 / 装修 / 口腔 / 家政 / 本地服务）
- 有专业 / 有手艺的从业者（老师 / 律师 / 医生 / 设计师等）
- 产业上游和手艺人（工厂 / 农产品 / 批发 / 原产地）
- 35+ 职场转型者
- MCN 编导和品牌运营

#### 3.2 不写给谁（约 350 字）
- 想 7 天起号的（节奏不对）
- 只想火不想变现的（路径不对）
- 不愿动手填的（设计前提不对）
- 兜底反问："读完第一件要动手做什么"

#### 3.3 三种读法（约 850 字）
- A 从头读（3-4 周一轮）
- B 按问题跳读（哪卡读哪）
- C 当工具书查（带团队 / 培训）
- 一句话决策器：痛点说不出走 A，说得出走 B，带人走 C

### 4. 收口动作清单（约 200 字）
- 确认你属于五类的哪一类
- 选定 ABC 一条路径
- 准备四件物理工具
- 收藏文章半年后回看
