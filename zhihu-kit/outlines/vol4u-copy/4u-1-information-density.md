# 4u-1 大纲 · 信息密度 + 拖时间不是注水

## 锚定

- **改写源**：`website/src/app/(playbook)/playbook/copywriting/page.tsx` 的 4U.0（导读 · 信息密度）+ 4U.1（文案的本质是拖时间）
- **结构索引**：`vol04-copy-scripts.md` 4U.0 + 4U.1

- **字数目标**：7000-8000（去格式后）

## 改写策略

- **核心要点必须命中**：
  - 干货 vs 信息密度（创作者视角 vs 平台视角）
  - 完播时长是平台分发流量的核心权重（两条公理 + 一个推论）
  - 拖时间 ≠ 注水（拖时间是埋钩子，注水是稀释）
  - 三档密度模型（低 / 高 / 超高）
  - 时间轴上的"切片"
  - 空间轴上的"多感官"
- **案例替换**：避开手册原例「做眼镜的 0~1500 度」，全部换成 3 组新案例
  - A 成功（切片）：某穿搭垂类号「同一件衬衫穿在 5 种身材上」
  - B 失败对比（伪干货）：某 To B 培训讲师号「每条都是教学公式但没人看完」
  - C 小案例（空间轴/感官）：某美食号「关掉声音就完全没意思了」
- **关键禁忌**：
  - 不照贴手册"两条公理 + 一个推论"原段，要改写说理路径
  - 不用「掰开揉碎」「干货满满」这类油腻口吻
  - 「拖时间」是反共识断言，但要给读者预防"这是不是在骗人"的反对意见处理
  - 不暴露 `weelume.com` / 内部编号 / 采集机制

## 结构

### 1. 钩子（约 500 字）
- 反常识对比：A 掏心掏肺日更干货，三位数播放；B 几乎什么也没讲，百万播放
- "你不是没价值，是你的地图错了"
- 抛出核心断言：**短视频文案的第一指标不是"你讲了什么"，是"你拖住了多久"**

### 2. 真实案例（约 1500 字 · 3 个）

#### 案例 A · 成功的「切片」（550 字）
- 某穿搭垂类博主：同一件白衬衫穿在 5 种身材上（梨形 / 苹果型 / H 型 / 沙漏 / 倒三角）
- 一条视频 = 5 个微切片
- 用户进来想看自己的身材类型，但被前几种切片勾着停留
- 数据走出：单条 50w 播放，对照该博主上月「白衬衫选购的 5 个建议」（同选题）的 2w 播放

#### 案例 B · 失败的「伪干货」（500 字）
- 某 To B 行业培训讲师：开账号 11 个月，发了 230 条，全部"今天来教大家 XX"
- 单条信息密度高（5 个知识点 / 90 秒）、PPT 一镜到底
- 平均播放 700，平均观看时长 2.4 秒
- 关键诊断：他做的是创作者视角的"密度"——知识点密集；不是平台视角的"密度"——刺激点密集

#### 案例 C · 关掉声音就没意思了（400 字）
- 某美食号——纯 ASMR 流派，画面平稳、口播极少，主要靠"切菜声、油锅滋滋声、咀嚼声"撑完播
- 把声音关掉看一遍——你会发现画面其实平平无奇
- 空间轴的感官刺激，是肉眼看不见但脑子记得住的东西

### 3. 主体（约 5000 字）

#### 3.1 干货 vs 信息密度（约 800 字）
- 「干货」是创作者视角——我准备了多少有用的内容
- 「信息密度」是平台视角——单位时间留住了多少注意力
- 两个视角的错位：一个三分钟干货视频结论 5 秒讲完 → 平均观看 7 秒；一个三分钟切片视频"什么都没讲" → 平均观看 2 分 20 秒
- 反对意见处理：「这难道不是反智吗？」——不是。是先有完播再有传播，没有完播你的"价值"根本到不了观众面前。
- 失败归因：为什么大部分人卡在低密度——他们在用电视台逻辑做短视频。

#### 3.2 平台为什么这么算（约 900 字 · 两条公理 + 一个推论）
- 公理一：所有 APP 的本质竞争是时间的竞争
  - 抖音不是和别的短视频抢，是和睡眠/饭局/球赛/游戏抢
  - 平台必然把流量给"让用户多停留"的内容——这是经济决定的，不是你能投诉的
- 公理二：越难作弊的参数越可信
  - 点赞可刷、关注可买、评论可批量，但每个用户的一分钟只能贡献一分钟
  - 完播时长是平台的"最后底牌"
- 推论：停留即真爱——时间不能复用
  - 用户嘴上喜欢可以是客套，他愿意把这 60 秒花在你这里、放弃下一刷，这是排他性的可信度
  - 完播是所有指标的"乘号左边"
- 反对意见处理：「我有几条点赞过万但播放不行的视频，怎么解释？」——孤例不破公理，是早期推荐池的样本噪声。

#### 3.3 拖时间 ≠ 注水（约 900 字）
- 「拖时间」第一次听到会觉得功利、甚至冒犯
- 但拖时间不是注水——注水是无目的稀释，拖时间是每一秒都在埋钩子/给悬念/做反转
- 怎么判断你是在"注水"还是在"拖时间"：
  - 拖时间的句子：删掉就会断悬念
  - 注水的句子：删掉了观众完全感觉不到
- 失败归因：为什么"为了拖时间"反而拖出注水——把"拖时间"误解为"多讲几句"，结果每一句都是稀释，没有一句是钩子

#### 3.4 三档密度模型（约 1000 字）
- 低密度（普通视频，三位数播放）
  - 三分钟讲一件事，开头到结尾只有一个信息点
  - 用户在前 5 秒滑走，不是不喜欢，是"后面没新东西"
- 高密度（热门视频，五~六位数）
  - 三分钟切成十段，每段 2-3 秒一个新画面/新信息
  - 用户每隔几秒被钩一下，没疲惫就被吊起来
- 超高密度（爆款视频，七~八位数）
  - 在时间轴切到极致后，再往空间轴加东西
  - 每一秒同时打三种感官（画面 + 声音 + 节奏）
- 反对意见处理：「我做的是慢节奏纪实内容，是不是注定做不出来？」——慢节奏不等于低密度，慢节奏只是"画面切换慢"。一条 2 倍速也能跟下去的"慢"视频，本质是低密度。
- 失败归因：很多人误把"画面切得快"当成密度。画面切得快但每个切片都没新信息，等于切了个寂寞。

#### 3.5 时间轴上的切片（约 800 字）
- "切片"是把一个三分钟的视频拆成十个 18 秒的小片段
- 每个小片段自带一个微悬念或微反转
- 用户看到的不是一个视频，是十个互相勾着的微视频
- 通用切片模式：
  - 对比类（之前 / 之后、A / B、5 个变体）
  - 进阶类（0 → 1 → 10 → 100、新手 → 熟手 → 高手）
  - 反差类（你以为 / 其实、外行看 / 内行看）
- 失败归因：为什么很多人切了 10 段还是没人看——10 段之间没有"勾连"。每一段都是独立信息，没有给下一段"立"一个引子。

#### 3.6 空间轴上的多感官（约 600 字）
- 同一时间往画面里多塞一个抓眼的元素（背景里的动作、并置的对比、镜头的反差）
- 声音也是一种"看不见的密度"——切菜声、开瓶声、ASMR
- 一个人讲话 + 背景里一只猴子拉摇晃的物件——播放翻倍
- 警告：感官刺激不能盖过主体，否则反而是"分散"而不是"加密"

### 4. 收口动作清单（约 300 字）

1. **拿你最近一条视频，按每 5 秒一格切开**——逐格回答这一格输出了几个信息点（视觉 + 听觉 + 文案各算一个）。3 个以下是低密度。
2. **找一条同行的爆款，用「切片」框架反向拆**——它把哪一件事拆成了几段、段与段之间用什么勾连。
3. **把下一条脚本改成切片结构**——选一个对比/进阶/反差模式，强迫自己拆成至少 5 段。
4. **关声音看一遍 + 关画面听一遍**——分别检查"画面是不是平平无奇"和"声音是不是空荡荡"，缺一个就补一个。
