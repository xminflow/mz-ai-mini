# 专栏篇目地图

专栏总名：**《自媒体运营实战》**

合计 **38 篇正文**（2 序章 + 36 主题长文）。每篇 7000-8000 字，对应手册 1-4 节内容合并改写。

## 篇目设计原则

- 单篇 = 一个完整主题，覆盖手册同一卷内 1-4 节相关内容
- 合并不是机械相邻，是按主题内聚度合（例：1.0 三条公理 + 1.1 做正确>做多 + 1.2 知识有对错 是同一个主题脉络，合一篇）
- 每篇 7000-8000 字，叙事密度比手册节更厚（多案例、多反对意见处理、多失败归因）
- 知乎专栏总字数约 28-30 万，与手册 18 万同量级（叙事展开形态比工具书形态字数自然更多 50%）

## 锚定来源

- **节级结构索引**：`ua-agent/frontend/resources/skills/weelume-playbook-advisor/references/vol0X-*.md`
- **改写源（正文蓝本）**：`website/src/app/(playbook)/playbook/<chapter>/page.tsx`
- **创作计划**：`asserts/2026-05-17-自媒体运营手册-book.md`

知乎专栏定位为手册的「叙事展开版」（非压缩版）：内容股一致、立场一致，形态从工具书改为长文叙事。详见 `style-guide.md` 第 0 节。

## 状态字段

- `planned` — 已规划未开始
- `outlining` — 大纲撰写中
- `drafting` — 草稿撰写中
- `reviewing` — 草稿完成，自审 / 送审中
- `ready` — 定稿，待发布
- `published` — 已发布到知乎
