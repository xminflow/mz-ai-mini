# 流量逻辑维度诊断要点

## 核心前提：99% 的"流量问题"其实是内容问题

手册 6.0 的核心结论：**99% 的播放低 = 内容问题，不是算法问题**。

诊断流量维度前，先排除前三个维度（定位/选题/钩子-兑现）的影响。如果前三个维度都有红灯，流量问题大概率是它们的下游表现，单独诊断流量维度意义不大。

## 诊断问题 1：账号标签是否稳定

**判定标准**：算法能否给账号打出清晰、稳定的内容标签和人群标签。

**怎么诊断**：

- 内容标签：近 10 条作品的主题词、视觉元素是否高度一致
- 人群标签：近 10 条作品的目标人群是否高度一致
- 用户标签：评论区、私信、留资的人群画像是否稳定

**红灯信号**：
- 同一个账号近期内容覆盖 ≥3 个差异巨大的赛道
- 评论区人群画像非常分散
- 平台推荐时跨人群混发

**对应手册章节**：6.4 三级标签机制（内容/账号/用户三级）

## 诊断问题 2：完播长度是否符合算法预期

**判定标准**：算法看的不只是"完播率"，而是**完播长度的三维**：

1. 平均完播长度（绝对秒数）
2. 完播率（百分比）
3. 完播分布（前 3 秒、前 1/3、过半、看完各占多少）

**红灯信号**：
- 前 3 秒留存率低 → 钩子问题
- 前 1/3 留存率低 → 钩子-兑现脱节
- 过半留存率低 → 中段节奏问题
- 完播低 → 收尾问题

**对应手册章节**：6.2 完播长度三维

## 诊断问题 3：是否符合算法三段

算法识别一条作品分三段：

1. **识别**：提取标签、特征、内容类型
2. **聚类**：匹配相似内容的历史人群
3. **排名**：在该人群池中竞争推荐位

**怎么诊断**：

- 识别段：标题/封面/开头是否包含明确的内容标签词（关键词、行业词、人群词）
- 聚类段：评论区是否聚集了目标人群（不是泛人群）
- 排名段：作品的完播、互动、转发指标是否在同类作品中具有竞争力

**红灯信号**：
- 标题没有明确关键词，算法识别困难
- 评论区被泛粉/僵尸粉占据
- 互动指标长期低于同类账号

**对应手册章节**：6.1 算法三段

## 诊断问题 4：是否触犯"五个不要"

手册 6.7 反共识"五个不要"：

1. **不要频繁换赛道**：算法刚识别完一类，又给到另一类，标签紊乱
2. **不要追求"蹭粉"**：买量、互推、僵尸粉会导致非自然增长被算法识别并限流
3. **不要靠 DOU+ 撑数据**：DOU+ 只能放大已经验证的内容，不能救烂内容
4. **不要撞热点撞到失焦**：蹭热点蹭离了账号母题，反而打乱标签
5. **不要"养号"玄学**：刷视频、点赞、僵尸操作，并不能"养"出账号

**怎么诊断**：

逐条问用户：
- 近 3 个月切过赛道吗？
- 有没有买过僵尸粉、僵尸互动、僵尸完播？
- DOU+ 投放是否在追求"流量起死回生"？
- 蹭热点的频率有多高？蹭过哪些？
- 是否信"养号"那套？

任意一条命中 → 流量维度的优先级直接**高**。

**对应手册章节**：6.7 五个反共识"不要"

## 诊断问题 5：DOU+ 使用是否合理

**判定标准**：DOU+ 只对**已经自然跑出小数据**的作品有效（自然播放 ≥1 万 + 完播率达标）。

**红灯信号**：
- 给冷启动失败的作品投 DOU+，期望"救活"
- 投放金额超过该条作品的预期变现回报
- 长期依赖 DOU+ 撑账号，自然流量基本没有

**对应手册章节**：6.8 DOU+ 投放公式

## 诊断问题 6：是否有数据看板和复盘节奏

**判定标准**：用户是否定期看自己作品的数据，并基于数据迭代。

**红灯信号**：
- 不看后台数据
- 看了但不知道哪些指标重要
- 看完没有迭代动作

**对应手册章节**：6.10 个人数据看板

## 优先级判定

- **高**：触犯"五个不要"中任意 1 条、标签严重紊乱、长期靠 DOU+ 撑场面
- **中**：完播长度问题、识别-聚类有问题但内容本身能改
- **低**：流量逻辑基本符合，只是排名段还可优化

修改成本：
- 改标题/封面让算法识别更清晰 → **低**
- 重建标签稳定性（停止换赛道、修选题） → **中**（需 1-2 个月数据洗）
- 已被限流（买过僵尸粉等） → **高**，往往需要重启账号

## 常见误判提醒

- 不要把所有流量低都归算法——99% 是内容问题
- 不要盲目相信"养号""玄学操作"——它们不会改善流量
- 不要看单条数据下结论——至少看 10-30 条的均值和分布
- 不要忽略"用户标签"维度——评论区被泛粉占据是慢性问题
