# 钩子-兑现链维度诊断要点

## 诊断问题 1：前 3 秒钩子是否清楚

**判定标准**：观众在前 3 秒能不能知道"这条视频跟我有什么关系，我为什么要看"。

**怎么诊断**：抽 5 条近期作品的开头 3 秒（标题 + 开场白），逐条判断属于五种开头模板的哪一类：

1. 好奇缺口
2. 直接利益
3. 共情场景
4. 反差冲击
5. 模式打破

**红灯信号**：
- 5 条里有 ≥2 条无法归类到任何一种 → 钩子模糊
- 5 条全用同一种模板 → 单调，长期会失效
- 钩子和后面内容脱节（标题党）

**对应手册章节**：4U.3 五种开头模板

## 诊断问题 2：中段是否兑现承诺

**判定标准**：开头钩子里给的承诺，在中段是否被具体回答。

**怎么诊断**：取 1 条作品，把开头钩子的"问题/承诺"提取出来；再看中段每一段，是否在朝这个问题推进。

**红灯信号**：
- 标题/钩子说要讲 A，中段绕开 A 讲 B
- 中段塞了太多副议题，主线被稀释
- 中段冗长但没有兑现关键承诺

**对应手册章节**：4U.2 起承转合四段结构

## 诊断问题 3：中段是否有"小列车"节奏

**判定标准**：每一段中段是否都自带一个小高潮（让观众想再看 5 秒）。

**怎么诊断**：把中段按 5-10 秒分段，看每段是否有小金句/小悬念/小反转。

**红灯信号**：
- 中段一路平铺，没有起伏
- 中段全靠语速快撑场面，缺真正的小高潮
- 中段每段长度过长（>15 秒），观众失耐心

**对应手册章节**：4U.4-bis 小列车原则

## 诊断问题 4：收尾是否落点

**判定标准**：结尾让观众产生动作（点赞/评论/收藏/关注/转发）或留下印象（金句/反转/留白）。

**怎么诊断**：抽 5 条近期作品的最后 3 秒，判断属于五种收尾的哪一类：

1. 行动诱因
2. 反问
3. 留白
4. 反转
5. 观点回扣

**红灯信号**：
- 收尾平收（"今天就讲到这里"、"希望对你有帮助"）
- 收尾过硬强制要求互动（"快点赞关注啊宝子们"）
- 收尾和开头钩子无呼应

**对应手册章节**：4U.5 五种收尾模板

## 诊断问题 5：信息密度是否均衡

**判定标准**：每 5 秒画一道线，看密度是否有起伏。

**红灯信号**：
- 全程高密度无喘息 → 观众疲劳划走
- 全程低密度无干货 → 看完没收获，不会点赞
- 信息高峰过早出现（开头爆点完，后面没东西）

**对应手册章节**：4U.0 信息密度原则

## 诊断问题 6：脚本类型是否匹配账号阶段

**判定标准**：观察型 / 教学型 / 叙述型 / 展示型 — 是否对位（手册 4D）。

**对照**：

| 账号阶段 | 推荐主打 | 红灯信号 |
|---------|---------|---------|
| 起步期（< 1 万粉） | 教学型 + 叙述型 | 起步就大量做观察型（观点输出），观众没建立信任 |
| 成长期（1-10 万粉） | 教 + 述 + 观 平衡 | 单一类型占比 > 80%，账号容易陷入瓶颈 |
| 变现期（> 10 万粉） | 观察型 + 展示型 | 还在大量做工具型教学，无法承接客单价 |

**对应手册章节**：4D 四型脚本

## 诊断问题 7：单向阀五问是否过

发布前用五问预设观众视角：

1. 这条视频跟我有什么关系？
2. 我看完能带走什么？
3. 我为什么要看你说而不是别人？
4. 这条值得我花 60 秒吗？
5. 看完我会想发给谁？

任意一题答不出来 → 钩子-兑现链有空洞。

**对应手册章节**：4U.6 单向阀（前置五问）

## 优先级判定

- **高**：标题党严重（钩子-兑现脱节）、5 条里 ≥3 条钩子模糊、信息密度严重失衡
- **中**：收尾平收、缺小列车节奏、脚本类型与账号阶段不匹配
- **低**：钩子-兑现整体可用，只是节奏需要进一步打磨

修改成本：
- 重写钩子和收尾、补小列车节奏 → **低**（针对下一条）
- 调整脚本类型主打 → **中**（需要 1-2 个月迭代）
- 重建表达体系 → **高**

## 常见误判提醒

- 不要因为"语速太慢"就判钩子-兑现有问题——可能是表达节奏问题，可单独提
- 不要因为"标题不吸引人"就只改标题——往往钩子整体（标题 + 封面 + 开场白）都要重写
- 不要把单条爆款失败归因到钩子-兑现链——可能是选题问题
