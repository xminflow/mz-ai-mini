# 定位维度诊断要点

## 诊断问题 1：能否用一句话讲清这个账号

**判定标准**：用户口述定位、近 10 条作品的人群和场景，能不能用"我帮 X 人，在 Y 场景，解决 Z 问题"概括。

**红灯信号**：
- 用户说不清自己服务谁
- 近 10 条作品中，能识别出 ≥3 个不同目标人群
- 用户描述时含糊地说"年轻人""女性""创业者"这类大词

**对应手册章节**：2.3 内容定位三原则（窄而深）、2.4 痛点 + 方案超级公式

## 诊断问题 2：是否存在定位漂移

**判定标准**：近期作品的主题、人群、场景是否在窄范围内反复，还是在大范围内跳跃。

**红灯信号**：
- 同一周内的作品分别面向 3+ 个不同人群
- 标题风格、视觉风格、表达方式在几条作品间剧烈变化
- 出现"跟风型"作品（赛道无关的热点蹭粉）

**对应手册章节**：2.3 内容定位三原则（重复而稳定）、6.4 三级标签机制

## 诊断问题 3：商业阶梯是否匹配

**判定标准**：用户的商业目标处在四阶梯哪一阶，现有内容能否承担那一阶的角色。

**四阶梯对照**（手册 2.2）：

| 阶梯 | 内容角色 | 常见错配 |
|------|---------|---------|
| 1 引流变现 | 内容做入口，承接私域/低客单 | 起步就强求做品牌，内容承载不动 |
| 2 个人 IP 变现 | 内容塑造人设、积累信任 | 内容只追流量，缺人设线 |
| 3 品牌变现 | 内容做品牌资产，承接带货 | 没建立人设基础就直接带货 |
| 4 系统变现 | 内容做矩阵示范 | 单号内容质量没起来就上矩阵 |

**红灯信号**：用户想做第 3 阶变现，但内容还停留在第 1 阶的工具型科普——这是最常见错配。

## 诊断问题 4：是否有视觉锤与文字钉

**判定标准**：观众是否能闭着眼形容这个账号的视觉、看一眼标题就知道是谁。

**红灯信号**：
- 没有反复出现的视觉元素（背景/服装/字幕/道具）
- 没有反复出现的口头禅、固定标题句式或固定开场白
- 几条作品摆在一起，看不出是同一个账号

**对应手册章节**：2.5 视觉锤与文字钉

## 诊断问题 5：是否有向下兼容空间

**判定标准**：账号如果跑出来，能延伸到 2-3 个相邻赛道；如果起步赛道太极端，未来无路可走。

**红灯信号**：
- 起步赛道完全没有相邻赛道（如"宠物搞笑"几乎无法兼容到商业）
- 起步赛道太宽，已经覆盖所有可能性，无处可去（如"生活分享"）

**对应手册章节**：2.6 向下兼容

## 诊断问题 6：IP 前置六问是否答清

把六问列给用户看，让他自查：

1. 你是谁？（一个标签）
2. 你说什么？（一类母题）
3. 你为谁说？（一类具体人）
4. 你和别人有什么不同？（一句对比句）
5. 你怎么持续地说？（题材供给系统）
6. 你最终想被记住什么？（一句话）

任意一题答不出来或答得含糊 → 定位问题大概率是优先级**高**。

**对应手册章节**：2.7 IP 前置规划六问

## 优先级判定

定位维度问题的优先级建议：

- **高**：定位句讲不清、出现明显漂移、商业阶梯严重错配（这三类问题不解决，其他维度优化都是徒劳）
- **中**：缺视觉锤/文字钉、未做向下兼容评估
- **低**：定位描述已经清楚，只是需要更精炼

修改成本：
- 重写定位句、补 IP 六问 → **低**（一次性工作）
- 调整商业阶梯期望、切换变现路径 → **中**
- 切换垂直赛道、重启账号 → **高**
