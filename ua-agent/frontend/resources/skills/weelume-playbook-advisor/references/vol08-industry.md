# 番外卷 行业战斗卷 索引

## X.0 四问分析框架

诊断/拆解任何一个行业账号，先问四题：

1. 博主是谁？（身份、积累、辨识度）
2. 目标受众是谁？（具体到处境、欲望）
3. 钩子是什么？（前 3 秒抓住观众的方式）
4. 变现路径是什么？（短视频 → 直播 → 私域 → 复购 各做什么）

**适用问题**：用户问"怎么分析一个行业账号"、"我该怎么定位我的行业"

## X.1 实体行业

适用：开店做生意、本地服务、线下商品。

**核心**：直接面向消费者的信任型转化。

- 短视频期：建立"老板/师傅/手艺人"的信任感（讲后厨、产品溯源、行业知识、日常工作）
- 直播期：批量转化、爆款种草
- 案例参照：小贩海鲜（441 万粉、年销 2 亿）/ 巨浪码头（11.5 万粉、月销 200 万）/ 贺先生海鲜批发（1.2 万粉、月流水 10 万+）

**适用问题**：用户问"我做实体店怎么做账号"、"做本地服务可以做账号吗"

## X.2 职业行业

适用：摄影师、医生、律师、设计师、教师、健身教练、咨询师等专业人士。

**核心**：用本职专业输出到一个比本职更大的市场（手册原文："摄影 ≠ 变现，摄影是话语权的载体，话语权才是变现的真正杠杆"）。

- 三条变现路径：2C 标品课 / 2B 行业服务 / 跨界带货
- 跨界示例：摄影师 → 用"教普通女生拍出明星感"切入女装
- 案例参照：蔡仲阳手机摄影 / 小叶老师手机摄影 / 智伪首饰摄影（2B）/ 胡楚镜（跨界带货 968.6 万）/ 江以浩（模特出身做男装）

**适用问题**：用户问"我是 X 职业怎么做账号"、"做专业服务怎么跨界"

## X.3 教培行业

适用：成人技能培训、儿童教育、知识付费。

**核心**：

- 成人教育 = "知识打架 + 泛话题破圈 + 直播间先讲干货再上课"（参照大天使英语三件套）
- 儿童教育 = "家长焦虑场景闭环 + 早晨黄金时段"（参照冉然格书法 60 秒闭环）

**少儿教育付费窗口**：付费集中在小学 1 年级到初一这一阶段；进入初二之后转化率断崖式下降。
**少儿教育黄金直播时段**：早上 7-9 点（妈妈做早饭/送孩子/坐公交上班的场景）。

- 案例参照：大天使英语（30 天 741 万、成人英语）/ 冉然格书法（499 元课卖 1647 单）/ 家师未报（少儿自驱力）/ 沈一读书（半读红楼）/ 英语雪梨老师（少儿英语知识点）

**适用问题**：用户问"做教培怎么做账号"、"做知识付费怎么开始"

## X.4 产品零售行业

适用：服饰、母婴、家居、装备、食品等实物零售。

**核心**：男性消费心理（功能优先、决策快）vs 女性消费心理（对比慢、情绪重）。

**三条路径**：

- 品牌矩阵型（参照海澜之家：N 子账号 + 13-17 小时直播 + 标品供应链）
- 专家 IP 型（参照衬衫老罗：81.6 万粉、年销 1.14 亿、25 年制衣经验、客单 59-99 元）
- 亚文化圈层（参照铁血缝纫机：年销 2.55 亿、20 小时/天直播、员工代播 SOP）

**反例**：TopUncle 品控塌方 → 差评增加 → 推荐权重下滑 → 直播间推流减少 → 场观持续下降。手册原文："实物零售的天花板从来不在前端内容，而在后端供应链"。

**适用问题**：用户问"做服饰怎么开账号"、"我是做实物的怎么搞"

## X.5 数字产品 / 知识变现

适用：电子产品（PPT、模板、提示词）、虚拟服务、SaaS、付费内容、加盟咨询。

**核心**：无库存、无物流、无供应链；用"钩子层 / 主力层 / 利润层"三层阶梯做升单漏斗。

**手册阶梯三层**：

- **钩子层 9.9-99 元**：单次课 / 试听课 / 电子手册 — 不为赚钱，为筛选 + 建立信任 + 引导高客单
- **主力层 99-1999 元**：标品课 / 短期训练营 — 跑量
- **利润层 1999-19,999 元**：1V1 私教 / 加盟培训 / 专家咨询 — 每卖一份相当于主力层 30 单

**关键边界**：钩子层和利润层之间必须有真实连续性 — "如果钩子层是骗进来的，用户走两步就跑了"。

- 案例参照：美容升单漏斗（39.9 元手部美白 → 16,900 元全身美容套餐）/ 饺子加盟（5,999 基础班 / 9,999 中级班 / 19,999 高级班）

**适用问题**：用户问"做数字产品怎么开始"、"做虚拟服务可以做账号吗"

## X.6 通用五步法

不分行业的通用打法：

1. **方向**：选定垂直母题
2. **痛点**：找到目标人群的 1-3 个高频痛点
3. **脚本选型**：决定主打哪种脚本类型（观察/教学/叙述/展示）
4. **测试**：小范围跑数据，验证哪条选题/钩子有效
5. **放量**：把验证过的模式复制扩量

**配套：竞品研究四关键词**：行业 / 用户 / 问题 / 产品。

**配套：六维分析**：定位 / 优势 / 视觉 / 价值 / 增长驱动 / 学什么 vs 避什么。

**适用问题**：用户问"通用打法是什么"、"任何行业都可以怎么做"

## X.7 30 账号样本库练习

每周看 10 个账号 × 3 周 = 30 个账号样本库，覆盖本行业头部 / 中部 / 尾部。

**目的**：把行业打法内化到肌肉记忆。

**适用问题**：用户问"怎么快速学一个行业"、"怎么调研竞品"

## 引导边界

本卷在问答顾问中**只做框架索引**。如果用户问的是"我做 X 行业，给我做整体打法拆解"——这是**生成式**任务，应该引导到 `weelume-industry-playbook` skill。

判定：

- 用户问"我该走五步法的哪一步" → 本 skill 答（问答）
- 用户问"我做花艺培训，从 0 到变现整套打法" → 引导到 `weelume-industry-playbook`（生成式）
