# 第二篇 定位 索引

## 2.0 画等号

**核心**：定位 = 让"我"、"我说的话"、"看我的人"三者画上等号。

**适用问题**：用户问"什么是定位"、"定位有什么用"

## 2.1 六大优势自检

写定位前的六类自查：行业积累 / 经历 / 身份 / 资源 / 表达 / 信任。

**核心**：六项里至少 1-2 项明显，否则别硬上。

**适用问题**：用户问"我适合做哪个赛道"、"我没什么优势怎么办"

## 2.2 四级商业阶梯

| 阶 | 内容角色 | 典型变现 |
|----|---------|---------|
| 1 引流变现 | 内容做入口 | 私域、低客单产品 |
| 2 个人 IP 变现 | 人设即产品 | 课程、付费社群、咨询 |
| 3 品牌变现 | 账号即资产 | 带货、自有产品、跨界 |
| 4 系统变现 | 矩阵 + 系统 | MCN、品牌矩阵 |

**核心**：先想清自己到第几阶，再反推内容承担什么角色。

**适用问题**：用户问"我该做什么变现"、"什么时候开始变现"

## 2.3 内容定位三原则

三条硬约束：

- **窄而深**：宁可服务一小撮人到位
- **重复而稳定**：母题反复回到
- **能被复述**：用户能一句话讲清

**适用问题**：用户问"赛道是不是越宽越好"、"我是不是太垂直了"

## 2.4 痛点 + 方案超级公式

> **在 X 场景下，Y 人遇到 Z 痛点，本号给出 W 解法。**

**核心**：四个槽位都要具体，含糊则定位失效。

**适用问题**：用户问"我的定位句怎么写"、"定位到底要多具体"

## 2.5 视觉锤与文字钉

- **视觉锤**：反复出现的画面元素
- **文字钉**：反复出现的口头/标题元素

**核心**：观众闭着眼能形容你视觉锤，看一眼标题就知道是你。

**适用问题**：用户问"为什么观众记不住我"、"封面要不要统一风格"

## 2.6 向下兼容

**核心**：起步赛道要窄，但要能向下兼容 2-3 个相邻赛道。

**适用问题**：用户问"赛道窄了以后没路怎么办"、"现在垂直会不会限制未来发展"

## 2.7 IP 前置六问

正式开号前要答清的六题：

1. 你是谁？
2. 你说什么？
3. 你为谁说？
4. 你和别人有什么不同？
5. 你怎么持续地说？
6. 你最终想被记住什么？

**适用问题**：用户问"开始拍前要准备什么"、"我没想清楚就开拍是不是错了"

## 2.8 寻找空白与做跨界

两种红海突围姿势：

- **空白扫描**：列头部 10 个账号，找他们没讲的角度
- **跨界借用**：把另一赛道的钩子/形式/视觉照搬

**适用问题**：用户问"赛道太卷怎么办"、"怎么做差异化"

## 2.9 定位卡片练习

最终交付物是一张 6 栏卡片（一句话定位 / 商业阶梯 / 内容母题 / 视觉锤 / 文字钉 / 向下兼容路径）。

**适用问题**：用户想要"一份定位模板" → 直接套这张卡片
