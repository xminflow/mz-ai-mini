# 第三篇 选题与素材库 索引

## 3.0 选题的本质

**核心**：选题不是"想到拍什么"，而是"找一个让观众停下来的情绪拐点"。

**判断三问**：

1. 目标观众会被哪种情绪勾起？
2. 看完能带走什么？
3. 看完会想发给谁？

三题答不上来 → 别拍。

**适用问题**：用户问"怎么知道选题好不好"、"为什么我的选题没人看"

## 3.1 六大情绪拐点

好奇 / 焦虑 / 愤怒 / 共鸣 / 惊讶 / 向往。每条选题都要打到其中至少 1 种。

**适用问题**：用户问"什么选题容易爆"、"我感觉自己的选题平平"

## 3.2 五方向选题矩阵

教育向 / 娱乐向 / 生活向 / 共情向 / 转化向 五个方向，**每个方向至少 5 条**，避免全堆在一处。

**适用问题**：用户问"选题怎么分类"、"我的选题是不是太单一"

## 3.3 热点借势四法

观点 / 解读 / 情绪 / 应用 四种合理借势方式。

**判定标准**：脱离热点后内容能不能单独成立。

**适用问题**：用户问"要不要追热点"、"蹭热点要怎么蹭"

## 3.4 八大爆款元素

反差 / 冲突 / 干货 / 悬念 / 共情 / 惊讶 / 节奏 / 金句。每条选题至少勾 2 项。

**适用问题**：用户问"什么是爆款"、"我的选题缺什么"

## 3.5 恒量 + 变量公式

> **恒量（母题）+ 变量（热点/情绪/角度/场景）= 一条新选题**

**核心**：先定 1-3 个恒量，再列 10-20 个变量来源，做笛卡尔积。

**适用问题**：用户问"怎么持续产出选题"、"选题枯竭怎么办"

## 3.6 素材库四分类

观点库 / 故事库 / 数据库 / 画面库。平时入库，拍时检索。

**适用问题**：用户问"素材怎么管理"、"我每次都临时找素材"

## 3.7 跨界选题借用

从相邻赛道借选题模板：

- 美妆 ← 穿搭风格分析
- 母婴 ← 心理学情绪命名
- 法律 ← 财经案例复盘

**适用问题**：用户问"赛道选题做光了怎么办"、"怎么做创新"

## 3.8 30 条起步选题库

新号开始前先做 30 条起步库，验证：

1. 恒量是否真能持续供给
2. 五方向是否都能写出
3. 是否能撑 2 周拍摄缓冲

**适用问题**：用户问"开始拍前要准备多少选题"、"选题要列多少条"
