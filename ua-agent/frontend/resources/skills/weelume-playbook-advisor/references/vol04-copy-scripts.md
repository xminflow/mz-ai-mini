# 第四篇 文案与脚本 索引

## 4U.0 信息密度

**核心**：短视频本质是密度，密度高 + 有起伏 = 留人。

**适用问题**：用户问"为什么观众看一半就走了"、"信息密度怎么把控"

## 4U.1 拖时间不是注水

**核心**：每一句能去掉的话都要去掉；保留下来的句子是为埋钩子/给悬念/做反转。

**适用问题**：用户问"脚本怎么删"、"哪些话是废话"

## 4U.2 起承转合四段

四段骨架：起（钩子）/ 承（展开）/ 转（升级）/ 合（落点）。缺一段就跑空。

**适用问题**：用户问"脚本结构怎么搭"、"脚本骨架是什么"

## 4U.3 五种开头模板（黄金三秒）

1. 好奇缺口
2. 直接利益
3. 共情场景
4. 反差冲击
5. 模式打破

**核心**：每条脚本必选一种，**不要混用**。

**适用问题**：用户问"前 3 秒怎么写"、"开头钩子怎么起"

## 4U.4 五种中段结构

顺叙 / 分点 / 对比 / 反转 / 层层递进。

**适用问题**：用户问"中段怎么展开"、"信息怎么排序"

## 4U.4-bis 小列车原则

**核心**：中段每一段自带小高潮，给观众"再看 5 秒"的理由。

**适用问题**：用户问"中段为什么会被划走"、"怎么让人看完"

## 4U.5 五种收尾模板

行动诱因 / 反问 / 留白 / 反转 / 观点回扣。

**核心**：收尾忌讳平收。必须给观众一个动作或一个余味。

**适用问题**：用户问"结尾怎么写"、"收尾要不要喊点赞关注"

## 4U.6 单向阀（前置五问）

发布前预设观众视角：

1. 跟我有什么关系？
2. 能带走什么？
3. 为什么要看你？
4. 值得花 60 秒吗？
5. 看完会发给谁？

**适用问题**：用户问"发布前怎么检查"、"自查清单是什么"

## 4U.7 感官 × 力度 × 封面

成片前最后三件事：感官（多通道）、力度（节奏起伏）、封面/标题（一眼看懂）。

**适用问题**：用户问"封面/标题要怎么做"、"成片前还要注意什么"

## 4D 四型脚本

按账号阶段匹配：

| 类型 | 形式 | 适合阶段 | 信任来源 |
|------|------|----------|----------|
| 观察型 | 对热点/现象的观点 | 成熟期 | 观点锐度 |
| 教学型 | 知识/方法传授 | 起步-成长期 | 信息密度 |
| 叙述型 | 个人故事/经历 | 起步-成长期 | 真实细节 |
| 展示型 | 过程/作品/场景 | 变现期 | 过程可见 |

**配比建议**：

- 起步期：教学 + 叙述 70/30
- 成长期：教 + 述 + 观 30/30/40
- 变现期：观 + 展 50/50

**适用问题**：用户问"我该用哪种脚本类型"、"什么阶段做什么内容"

## 4D.1–4D.4 四型脚本各自结构

- 观察型：抛现象 → 给判断 → 解释为什么 → 落到读者
- 教学型：说痛点 → 给方法 → 拆步骤 → 给例子 → 收行动
- 叙述型：进场景 → 起冲突 → 推进 → 高潮 → 落感悟
- 展示型：开始状态 → 过程关键点 → 结束状态 → 价值放大

**适用问题**：用户问"X 型脚本怎么写"、"我做的是 X 型，结构对吗"

## 4D.5 爆款拆解法

学他人脚本的方法：找爆款 → 听写逐字稿 → 标四段 → 标用了哪些模板 → 提炼骨架 → 用在下条。

**适用问题**：用户问"怎么学别人的脚本"、"看到好作品怎么拆"

## 4D.6 一条 3000 字脚本的工序

定选题 → 定脚本类型 → 写一句话承诺 → 拆中段 3-5 段 → 写收尾 → 通读删冗余 → 读出计时。

**适用问题**：用户问"完整脚本怎么写"、"3000 字脚本要花多久"
