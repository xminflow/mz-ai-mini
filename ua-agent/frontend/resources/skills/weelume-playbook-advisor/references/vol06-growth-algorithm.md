# 第六篇 增长 · 算法 · 投放 索引

## 6.0 99% 流量低 = 内容问题

**核心**：流量诊断的第一公理：99% 的流量低是内容问题，不是算法问题。

**适用问题**：用户抱怨"算法不公平"、"我的视频被限流了"、"为什么没流量"

## 6.1 算法三段

平台对每条作品的处理分三段：

1. **识别**：提取标签、特征、内容类型
2. **聚类**：匹配相似内容历史人群
3. **排名**：在该人群池中竞争推荐位

**适用问题**：用户问"算法怎么推流"、"为什么我的内容推给错的人"

## 6.2 完播长度三维

不是只看完播率，而是看：

1. 平均完播长度（秒）
2. 完播率（%）
3. 完播分布（前 3 秒 / 前 1/3 / 过半 / 看完 各占多少）

**适用问题**：用户问"完播率多少算好"、"完播怎么提"

## 6.3 垂直目的 + 多维方法

**核心**：账号要"垂直"，但表达可以"多维"。垂直的是人群和母题，多维的是选题角度和表达手法。

**适用问题**：用户问"垂直到底有多窄"、"内容是不是不能变"

## 6.4 三级标签机制

内容标签 / 账号标签 / 用户标签 三级共同决定分发。

**适用问题**：用户问"账号标签怎么打"、"我的视频推给的人不对"

## 6.5 赛马机制 + 超粉机制

**核心**：

- 赛马：新作品先在小流量池中竞争，跑赢才升池
- 超粉：粉丝中的核心粉触发后能拉动更大推荐池

**适用问题**：用户问"为什么有时候这条爆下条没"、"为什么粉丝看完作品后涨粉更多"

## 6.6 账号阶段的不同优先级

| 阶段 | 优先 |
|------|------|
| 冷启动 | 标签清晰、留存达标 |
| 成长期 | 互动率、复看率 |
| 稳定期 | 转粉率、私域转化 |

**适用问题**：用户问"我账号在哪个阶段""现在该优化什么"

## 6.7 五个反共识"不要"

1. **不要频繁换赛道**
2. **不要追求蹭粉**（买量、互推、僵尸）
3. **不要靠 DOU+ 撑数据**
4. **不要蹭热点蹭到失焦**
5. **不要相信"养号"玄学**

**核心**：触犯任一条就会让账号长期受损。

**适用问题**：用户问"该不该换赛道"、"DOU+ 投多少合适"、"养号有用吗"、"我蹭这个热点合适吗"

## 6.8 DOU+ 投放公式

**核心**：DOU+ 是放大器，不是救命药。只对**已经自然跑出小数据**的作品有效。

**判断**：作品自然播放 ≥1 万 + 完播率达标 → 可投；否则 → 别投。

**适用问题**：用户问"什么时候投 DOU+"、"DOU+ 怎么投"

## 6.9 平台规则与冷启动陷阱

冷启动的常见坑：

- 频繁删稿重发
- 同一文案多次重复
- 互动数据明显不自然（机器互动）
- 内容触犯敏感词

**适用问题**：用户问"为什么我的新视频没推荐"、"删稿重发可以吗"

## 6.10 个人数据看板

建议每周看的指标：

- 单条：完播率分布、平均完播长度、点赞率、收藏率、转发率、转粉率
- 账号：粉丝净增、人群标签变化、TOP 3 作品的特征

**适用问题**：用户问"要看哪些数据"、"数据怎么复盘"
