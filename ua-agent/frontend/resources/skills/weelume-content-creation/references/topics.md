# 选题方法论精华

## 3.0 选题的本质

选题不是"想到要拍什么"，而是**找到一个能让观众停下来的情绪拐点**。

判断一个选题值不值得拍，问三件事：

1. 这个选题，目标观众会不会在某一刻情绪被勾起？
2. 勾起的情绪是哪一种（好奇/焦虑/愤怒/共鸣/惊讶/向往）？
3. 看完后他能带走什么（判断/方法/情绪释放/身份认同/谈资）？

三条都答不出来，先不拍。

## 3.1 情绪拐点矩阵

观众停留的拐点大致来自 6 种情绪：

- 好奇：「这事我不知道」
- 焦虑：「这事跟我有关，且我没准备好」
- 愤怒：「这事不对，得说说」
- 共鸣：「我也是这样」
- 惊讶：「居然是这样」
- 向往：「我也想这样」

**用法**：写每条选题时，标清它打哪个情绪。情绪不清晰的选题往往会失败。

## 3.2 五方向选题矩阵

把选题拆成 5 个方向，每个方向反复供给，避免单一来源耗尽：

1. **教育向**：解决某个具体问题、传授某项具体能力
2. **娱乐向**：制造笑点、反转、表演性内容
3. **生活向**：呈现真实生活/职业场景的细节
4. **共情向**：替观众说出说不出口的话、戳到某种被压抑的情绪
5. **转化向**：直接面向变现的产品/课程/服务介绍

**用法**：30 条选题库，**每个方向至少 5 条**，避免全堆在"教育向"。

## 3.3 热点借势四法

蹭热点不是随便蹭，有四种合理姿势：

1. **观点借势**：对热点事件给出一个有判断力的观点
2. **解读借势**：把热点背后的原理/规律说清楚
3. **情绪借势**：放大热点引发的某种情绪（同情/愤怒/共鸣）
4. **应用借势**：把热点转化成对观众有用的具体做法

**判定标准**：借势后的内容能不能脱离热点单独成立。能 → 合格；不能 → 是在蹭，不是借。

## 3.4 八大爆款元素

爆款短视频通常含其中 2-3 项：

1. **反差**：身份反差、场景反差、结果反差
2. **冲突**：人物冲突、立场冲突、价值观冲突
3. **干货**：能立即拿走用的信息或方法
4. **悬念**：开头埋问题，结尾才解
5. **共情**：戳中观众未表达的情绪
6. **惊讶**：超出常识的事实或数据
7. **节奏**：剪辑节奏、语速节奏、画面节奏的反复推进
8. **金句**：能被截图、被复述、被传播的一句话

**用法**：每条选题至少能勾上 2 项，没有任何一项就不要拍。

## 3.5 恒量 + 变量公式

选题持续供给的核心公式：

> **恒量（账号的核心定位/母题）+ 变量（热点/情绪/角度/场景）= 一条新选题**

- **恒量**：每条都要回到的母题。例："35+ 女性转行"
- **变量**：热点借势、评论区提问、用户来信、跨界借用、个人经历、节气节日

**实操**：先写下 1-3 个恒量母题，再列 10-20 个可用变量来源，做笛卡尔积，就能在 1 天内生成 30+ 条选题。

## 3.6 选题素材库四分类

不要等到要拍才找素材，平时就建分类素材库：

1. **观点库**：你常说的判断、金句、立场
2. **故事库**：你/身边人/读者/历史人物的具体故事
3. **数据库**：你认证可信的数字、事实、案例
4. **画面库**：可重复使用的视觉素材、场景、道具

每条素材入库时打标签（情绪/方向/可用场景），方便检索。

## 3.7 跨界选题借用

红海赛道选题枯竭时，**从相邻赛道借选题模板**：

- 美妆赛道 → 借用穿搭赛道的"风格分析"模板
- 母婴赛道 → 借用心理学赛道的"情绪命名"模板
- 法律赛道 → 借用财经赛道的"案例复盘"模板

**用法**：列出 3 个相邻赛道，看他们的爆款用了什么结构，把结构借过来灌入自己的内容。

## 3.8 30 条起步选题库

新号起步，建议先做一个 30 条选题库再开拍，目的是：

- 验证恒量是否真的能持续供给（不能 → 定位太窄）
- 验证 5 方向是否都能写出选题（某个方向写不出 → 该方向可能不适合此账号）
- 形成 2 周以上的拍摄缓冲（不会被"明天拍什么"卡死）

**质量自检**：

- 是否每条都能回到恒量？
- 5 方向分布是否均衡？
- 是否有至少 3 条能直接接转化（导向产品/课程/咨询）？
- 是否有至少 5 条能借势近 30 天的热点/节气？
