# 文案与脚本方法论精华

## 4U.0 信息密度原则

短视频的本质是**密度**：

- 同样时长内，能给观众的判断/情绪/信息越密，留人能力越强
- 但密度过高会让人疲劳；密度过低会被划走
- 节奏控制 = 让密度有起伏，而不是一直高

**用法**：写完脚本后，把每 5 秒画一道线，看每段密度是否均衡。

## 4U.1 拖时间不是注水

短视频的写作本质是"让观众多停一秒"——但不是靠注水：

- 错误的拖时间：废话、铺垫、绕弯子
- 正确的拖时间：埋钩子、给悬念、做反转、设承诺、抛细节

**判定标准**：每一句话能不能去掉？能去掉 → 删；不能去掉 → 留。

## 4U.2 起承转合四段结构

通用骨架（无论什么类型脚本都适用）：

1. **起（钩子）**：3 秒内说清观众为什么要看
2. **承（展开）**：把钩子里的承诺一步步兑现
3. **转（升级）**：在某个点制造冲突/反转/递进
4. **合（落点）**：给观众一个能带走的东西

四段都要在，缺一段就会跑空。

## 4U.3 五种开头模板（黄金三秒）

短视频前 3 秒决定 80% 的留存。五种万能开头：

1. **好奇缺口**：「你知道为什么 X 总是 Y 吗？」「99% 的人不知道这件事」
2. **直接利益**：「想 X 的看这个就够了」「这条视频能帮你省下 X 元」
3. **共情场景**：「你是不是也经常 X」「我曾经因为 X 几乎崩溃」
4. **反差冲击**：「我月入 X 万，但每天只工作 2 小时」「学历高的人，反而最容易 X」
5. **模式打破**：突然换语气/突然停顿/突然抛出反常识结论

**用法**：每条脚本必选一种，**不要混用**。混用会让前 3 秒变模糊。

## 4U.4 五种中段结构

中段是兑现承诺的地方，五种结构挑一：

1. **顺叙**：按时间/步骤一路讲下去（适合教学、过程展示）
2. **分点**：列 3-5 个点逐项展开（适合知识/方法）
3. **对比**：A vs B 对照展开（适合观点、立场）
4. **反转**：先说一个常识，再推翻它（适合反常识内容）
5. **层层递进**：从浅到深、从轻到重逐步加码（适合长情绪/深度叙述）

## 4U.4-bis 小列车原则

中段每一段要像火车每节车厢一样，**自带一个小高潮**：

- 第 1 段末尾抛一个小悬念/小金句
- 第 2 段开头回应、再抛新的
- 第 3 段继续……

每段都给观众一个"再看 5 秒"的理由，否则会在中段被划走。

## 4U.5 五种收尾模板

收尾的目的是让观众产生行动（点赞/评论/收藏/关注/转发）。五种模板：

1. **行动诱因**：「评论区留下你的 X，下条视频给你拆」
2. **反问**：「你怎么看？说说你遇到过的 X」
3. **留白**：戛然而止，让观众回味
4. **反转**：最后一句把前面所有结论翻过来
5. **观点回扣**：把开头钩子里的问题用一句话彻底回答

**用法**：收尾最忌讳"那么今天就先到这里"这种平收。**必须给观众一个动作或一个余味**。

## 4U.6 单向阀（前置五问）

发布前用五问预设观众视角，提升重要性：

1. 这条视频跟我（观众）有什么关系？
2. 我看完能带走什么？
3. 我为什么要看你说而不是别人？
4. 这条值得我花 60 秒吗？
5. 看完我会想发给谁？

五问答不出来 → 标题/钩子/承诺还需要重写。

## 4U.7 感官 × 力度 × 封面

成片前的最后三件事：

- **感官**：画面、字幕、音乐是否给观众多通道刺激
- **力度**：表达是否有节奏起伏、语气是否有重音
- **封面/标题**：封面 3 字内能不能让人停下、标题能不能一眼看懂

## 4D 四型脚本（按账号阶段匹配）

不同账号阶段适合不同脚本类型：

| 类型 | 形式 | 适合阶段 | 信任来源 |
|------|------|----------|----------|
| **观察型** | 对现象/热点的犀利观点 | 成熟期，做思想领导力 | 观点的锐度和稳定性 |
| **教学型** | 知识点/方法的清晰传授 | 起步-成长期，建立专业度 | 信息密度和体系感 |
| **叙述型** | 故事/经历的个人讲述 | 起步-成长期，建立人设 | 真实细节和情感纹理 |
| **展示型** | 过程/作品/场景的呈现 | 变现期，建立可购买感 | 过程可见和成果可验 |

**起步期建议**：教学型 + 叙述型组合 70/30
**成长期建议**：教学 + 叙述 + 观察 各占 30/30/40
**变现期建议**：观察 + 展示 各占 50/50

### 4D.1 观察型脚本

结构：**抛现象 → 给判断 → 解释为什么 → 落到读者**

注意：观点必须有锐度，含糊的"中庸观点"会被划走。

### 4D.2 教学型脚本

结构：**说痛点 → 给方法 → 拆步骤 → 给例子 → 收行动**

注意：拆步骤时控制在 3-5 步，超过 5 步会失忆。

### 4D.3 叙述型脚本

结构：**进场景 → 起冲突 → 推进 → 高潮 → 落感悟**

注意：要给具体细节（时间、地点、人物对白），避免空泛抒情。

### 4D.4 展示型脚本

结构：**开始状态 → 过程关键点 → 结束状态 → 价值放大**

注意：过程要"可验证"，让观众相信你真的做过/做到。

## 4D.5 爆款拆解法

学习他人脚本的方法：

1. 找一条同赛道近 30 天的爆款
2. 把它的脚本逐字稿听写下来
3. 按 4U.2 起承转合标记四段
4. 标出它用了哪个开头模板、中段结构、收尾模板
5. 提炼可迁移的"结构骨架"，用在自己下一条视频上

**用法**：每周拆 1 条，月度积累 4 条骨架。

## 4D.6 一条完整 3000 字脚本的工序

1. 定选题（5 分钟）
2. 定脚本类型（观察/教学/叙述/展示）
3. 写一句话承诺（开头钩子的核心）
4. 拆中段 3-5 段，每段写微高潮
5. 写收尾，回扣开头
6. 通读，删冗余，让信息密度上来
7. 把脚本读出来计时，调整到目标时长

工序内不要跳步，跳步往往导致脚本松散。
