# 定位方法论精华

## 2.0 导读 · 画等号

定位的本质是**画三个等号**：

- 我 = 一个被记住的标签
- 我说的话 = 一类被相信的判断
- 看我的人 = 一个被服务的具体人群

定位不是用来给自己看的，是用来让观众一句话讲得清你是谁。

## 2.1 六大优势自检

写定位前，先做六类自查，避免凭空想象：

1. 行业积累优势：你做这件事比别人多了多少年
2. 经历优势：你有别人没有的亲历
3. 身份优势：职业、学历、地域、年龄给你的天然话语权
4. 资源优势：你能调度别人调不动的人/物/数据
5. 表达优势：你说话/出镜/写字的某一项明显胜出
6. 信任优势：已经在某个圈子内有口碑

**用法**：六项里至少 1-2 项明显，否则要重新选方向，不要硬上。

## 2.2 商业定位四阶梯

按你想达到的商业终点反向画路径，四阶梯由浅入深：

1. **第 1 阶 引流变现**：内容是入口，靠私域、咨询、低客单产品转化
2. **第 2 阶 个人 IP 变现**：以人设为产品，做课程、付费社群、咨询服务
3. **第 3 阶 品牌变现**：以账号为品牌资产，做带货、自有产品、跨界合作
4. **第 4 阶 系统变现**：以矩阵和系统为壁垒，做 MCN、品牌矩阵、平台合作

**用法**：先想清自己到第几阶，再反推内容承担什么角色。**不要把第 1 阶当成第 4 阶来做**——刚起步就强求"做品牌"是最大错配。

## 2.3 内容定位三原则

内容选什么、怎么说，受三条硬约束：

1. **窄而深**：宁可服务一小撮人到位，也不要服务所有人到一般
2. **重复而稳定**：母题反复回到、表达反复一致，比频繁换花样有效
3. **能被复述**：用户能用一句话向朋友讲清你做的是什么

## 2.4 痛点 + 方案超级公式

定位句的万能模板：

> **在 X 场景下，Y 人遇到 Z 痛点，本号给出 W 解法。**

四个槽位都要具体：

- X：具体场景（不是"生活中"，而是"35 岁第一次创业""女儿读初一"）
- Y：具体人群（不是"年轻人"，而是"刚转行做销售的"）
- Z：具体痛点（不是"焦虑"，而是"开口跟客户讲价没底气"）
- W：具体解法（不是"教你方法"，而是"7 套话术 + 2 种压价模型"）

## 2.5 视觉锤与文字钉

让观众一眼/一耳记住的两件东西：

- **视觉锤**：反复出现的画面元素——固定背景、固定服装、固定道具、固定字幕样式、固定开场动作
- **文字钉**：反复出现的口头/标题元素——固定口头禅、固定标题句式、固定开场白、固定收尾

**判定标准**：观众闭着眼能形容出你视觉锤的样子，看一眼标题就知道是你的内容，才算钉牢。

## 2.6 向下兼容

好定位要给自己留**扩展路径**：

- 起步赛道要窄，但其内容能力要能"向下兼容"到相邻 2-3 个赛道
- 例：从"35+ 转行女性"起，可向下兼容"女性独立"、"中年职场"、"成人技能学习"
- 反例：从"宠物搞笑"起，几乎无法向下兼容到任何商业赛道

**用法**：写完定位卡，问自己"如果跑出来，我能延伸到哪 2-3 个相邻方向"。如果一个都答不出来，定位太窄。

## 2.7 IP 前置规划六问

正式开号前，把这六题答完：

1. 你是谁？（一个标签）
2. 你说什么？（一类母题）
3. 你为谁说？（一类具体人）
4. 你和别人有什么不同？（一句对比句）
5. 你怎么持续地说？（题材供给系统的 1.0 版本）
6. 你最终想被记住什么？（一句话）

六问答不出来就不要开拍，先想清楚。

## 2.8 寻找空白与做跨界

红海里找路径：

- **空白扫描**：列出该赛道头部 10 个账号，把他们没讲的角度、没服务的人群、没用过的形式列出来
- **跨界借用**：把另一个赛道的钩子/形式/视觉照搬过来（例：把法律科普做成 vlog 形式、把美妆教程做成段子结构）

**注意**：跨界不是为了猎奇，是为了在红海里造一个新的辨识维度。

## 2.9 定位卡片练习

最终交付物是一张可填写的卡片，含 6 栏：

| 栏目 | 内容 |
|------|------|
| 一句话定位 | 我帮 X 人，在 Y 场景，解决 Z 问题 |
| 商业阶梯 | 第几阶 + 直接变现方式 |
| 内容母题 | 反复回到的 1-3 个母题 |
| 视觉锤 | 一个具体元素 |
| 文字钉 | 一句具体话 |
| 向下兼容路径 | 未来可延伸的 2-3 个相邻赛道 |

填完卡片，对照六问自查，再开拍。
