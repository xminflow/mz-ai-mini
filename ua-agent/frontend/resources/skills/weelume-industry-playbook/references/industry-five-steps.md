# 通用五步法（行业战斗卷的核心方法）

## 五步法总览

| 步骤 | 核心问题 | 输出物 |
|------|---------|--------|
| 1 方向 | 选什么垂直母题 | 一句话定位 + 2-3 个候选母题 |
| 2 痛点 | 找哪些用户痛点 | 1-3 个高频痛点 |
| 3 脚本选型 | 用哪种脚本结构 | 第 1 条测试视频的脚本骨架 |
| 4 测试 | 怎么验证有效性 | 数据看板 + 测试周期 |
| 5 放量 | 验证后怎么扩产 | 恒量 + 变量公式 + 节奏 |

## 第 1 步：方向

### 核心问题
要解决的是"我做什么"，不是"我能做什么"。**能做的事很多，但跑得动的方向往往只有 1-2 个**。

### 判断标准
方向是否合理，问三个问题：

1. **这个方向我有 6 大优势中的几项？**（手册 2.1 — 行业积累 / 经历 / 身份 / 资源 / 表达 / 信任）
2. **这个方向商业上能落到第几阶梯？**（手册 2.2 — 引流 / IP / 品牌 / 系统）
3. **这个方向能向下兼容到几个相邻赛道？**（手册 2.6）

三题答清楚，方向才能定。

### 反例
- 没有任何优势的方向 → 跑不起来
- 商业阶梯期望和现实条件错位的方向 → 内容承载不动
- 完全无向下兼容的方向 → 走入死胡同

## 第 2 步：痛点

### 核心问题
不是"我能解决什么问题"，是"用户高频被困扰且愿意付费解决的问题"。

### 判断标准
痛点是否合理，问三个问题：

1. **这是不是用户的"主诉"痛点，还是我以为是？**（用户口中反复说的，才算）
2. **痛点的紧急度有多高？**（不紧急的痛点 = 不会变现）
3. **用户愿意为解决这个痛点付多少钱？**（市场现有定价区间）

### 收集方法
- 看自己的客户咨询记录（真实主诉）
- 看同行评论区（用户在抱怨什么）
- 看竞品爆款（爆款选题往往打中真实痛点）
- 看搜索数据（百度指数、抖音热搜）

### 反例
- 自以为是的痛点（用户其实不在乎）
- 太宽泛的痛点（"焦虑""迷茫"——没法拍）
- 没人愿意付费的痛点（即使解决了也不能变现）

## 第 3 步：脚本选型

### 核心问题
不是"我喜欢哪种脚本"，是"目标人群和当前阶段最该用哪种"。

### 判断矩阵

| 行业类型 | 阶段 | 推荐主类型 | 推荐辅类型 |
|---------|------|----------|----------|
| 实体 | 短视频期 | 展示型 | 叙述型 |
| 实体 | 直播期 | 展示型 | 教学型 |
| 职业 | 短视频期 | 观察型 | 教学型 |
| 职业 | 成熟期 | 观察型 | 叙述型 |
| 教培（成人） | 短视频期 | 教学型 | 叙述型 |
| 教培（儿童） | 短视频期 | 教学型 | 展示型 |
| 产品零售 | 全期 | 展示型 | 教学型 |
| 数字产品 | 短视频期 | 教学型 | 展示型 |
| 数字产品 | 成熟期 | 教学型 | 观察型 |

### 第 1 条测试视频的骨架
拿到主类型后，按手册 4D 的四型脚本结构搭起来：

- 观察型：抛现象 → 给判断 → 解释为什么 → 落到读者
- 教学型：说痛点 → 给方法 → 拆步骤 → 给例子 → 收行动
- 叙述型：进场景 → 起冲突 → 推进 → 高潮 → 落感悟
- 展示型：开始状态 → 过程关键点 → 结束状态 → 价值放大

## 第 4 步：测试

### 核心问题
"用最少的成本验证方向 + 痛点 + 脚本是否对路。"

### 测试方法

- 发布数量：先发 10-15 条同一方向的作品
- 测试周期：2-3 周
- 看的指标：
  - 完播长度（前 3 秒留存 / 中段 / 收尾）
  - 互动率（点赞率 / 评论率 / 收藏率 / 转发率）
  - 转粉率（看完作品后关注的比例）
  - **私信/留资数**（最重要 — 表明用户愿意采取行动）

### 判定标准

- **跑通**：10-15 条里至少 2-3 条数据明显高于均值，且评论区有目标人群进入
- **没跑通**：所有作品数据持平，评论区是泛粉 → 回到第 1 步重选方向，或第 2 步重选痛点
- **半跑通**：某类作品数据明显高 → 把这类作为主打，淘汰其他

### 反例
- 测试期内频繁换方向 → 算法识别困难，所有数据都不准
- 测试期内追求"爆款" → 测试是验证方向，不是求爆款
- 测试期短于 2 周 → 数据不够

## 第 5 步：放量

### 核心问题
"验证通过后，怎么用最稳定的方式持续供给。"

### 放量公式（来自手册 3.5）

> **恒量（已验证的方向）+ 变量（新角度/新场景/新热点）= 持续选题**

### 放量节奏

- 内容频率：每周 4-7 条（不要突击高频，会导致质量下降）
- 选题库：保持 30+ 条储备
- 复盘节奏：每周看数据，每月调整变量来源
- 投放节奏：自然流量稳定后，对优质作品投 DOU+ 放大（手册 6.8）

### 防止失控的红线
- **不要换方向**：方向已验证就不要轻易换（除非数据持续下滑 ≥ 4 周）
- **不要乱投 DOU+**：只投自然流量已经跑出来的作品
- **不要相信"养号"玄学**：触发"五个不要"（手册 6.7）会让账号长期受损

## 配套工具：竞品研究四关键词

研究本行业头部账号时，按四个关键词拆：

1. **行业**：他做的具体行业是什么
2. **用户**：他的目标用户是谁
3. **问题**：他解决什么问题
4. **产品**：他卖什么

## 配套工具：六维分析

研究单个竞品账号时，按六维拆：

1. 定位（一句话能讲清吗）
2. 优势（六大优势中占哪几项）
3. 视觉（视觉锤是什么）
4. 价值（情绪/信息/实用价值的占比）
5. 增长驱动（什么在推动他增长）
6. 学什么 vs 避什么（哪些可借鉴、哪些是他独有不可学的）

## 配套工具：30 账号样本库

每周看 10 个账号 × 3 周 = 30 个账号样本库。

**用法**：把本行业头部 / 中部 / 尾部 / 跨界 / 反例 都纳入样本，建立"行业肌肉记忆"。
