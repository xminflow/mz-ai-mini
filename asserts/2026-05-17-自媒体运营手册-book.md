# 《自媒体运营手册》创作计划

> **给执行者（人或子代理）的说明：** 本计划用于按章节撰写一本约 15-18 万字的实战型自媒体运营手册。每一章都已给出"素材出处 + 提炼要点 + 关键案例 + 必出工具"四件套；执行时请按章节顺序写作，逐章提交后再开下一章。本文件本身使用 `- [ ]` 复选框跟踪进度。

**目标：** 基于 `material/鹤老师/` 与 `material/薛辉/` 两套素材，**融合**"底层逻辑派"（鹤老师）与"标准化训练营派"（薛辉 All-in 团队）两种方法论为**统一立场**，撰写一本面向实体老板、专业人士与个人 IP 创业者的、可直接落地的自媒体运营手册。

**核心主张（融合后的统一立场，不再并列两派说法）：**

1. 正确比多重要——伪命题（要不要养号、几点发、是否日更）不消耗读者注意力
2. 短视频是练会的——书里所有工具都是"今晚就能填"，不是"读完受启发"
3. 粉丝经济是终局——和流量保持顾客关系会越做越累，必须升级为信任关系
4. 信息密度优先——"短"不是时间短，是密度高；同样精彩越长越好
5. 向下兼容找比你弱的人；多维呈现服务于目的垂直

**写作风格约定：**

- 全书使用简体中文，面向中国大陆自媒体场景（抖音为主、视频号/小红书/B 站为辅）
- 平台名保留官方写法（"B 站""小红书""DOU+"），人物名保留真实姓名
- 每一节按"现象 → 反共识结论 → 推导 → 案例 → 工具"五段式写作，避免鸡汤罗列
- 案例必须真实可查（来自素材原文），不得编造数字
- 工具必须可填、可打印、可即用
- 涉及两位老师观点冲突的内容：**写作时直接采用第九节"已融合立场清单"给出的统一答案**，不在正文里展示两派分歧。读者不应该感受到这是一本"对照课程笔记"

**素材出处约定：**

- `[鹤·NN]` 表示鹤老师素材文件，如 `[鹤·40.第40集-鹤老师文案方法论]`
- `[薛·NN]` 表示薛辉团队素材，如 `[薛·02.薛辉：短视频8大爆款元素定位课（上）]`
- `[训·NN]` 表示鹤老师闪电训练营三天，如 `[训·第二天02]`
- 多个素材并列用分号分隔

## 一、读者画像与定位

**第一读者**：

- 已有一定生意/手艺/专业，但获客成本高、信任难建立的实体老板（餐饮、装修、口腔、二手车、家政、本地服务）
- 想从靠经验/熟人接单转向公域流量的专业人士（教师、律师、医师、设计师、摄影师、健身教练）
- 第一次系统做个人 IP 的中年/中产创作者

**第二读者**：

- MCN/品牌方的编导、运营
- 想转型的传统电商/线下零售管理者

**读者读完应当能做到：**

1. 判断自己适不适合做自媒体、做哪个平台、做哪种类型
2. 写出可执行的商业定位 + 内容定位
3. 独立完成选题 → 脚本 → 拍摄 → 剪辑 → 投放 → 转化的全链路
4. 在数据不好时知道往哪里改，而不是换赛道
5. 看到任何爆款都能拆解出其结构与可迁移要素

## 二、全书结构总览

全书共 **9 篇正卷 + 1 卷番外（行业战斗卷）+ 1 卷附录**。主线遵循"为什么做 → 做什么 → 写什么 → 怎么拍 → 怎么放大 → 怎么赚"的因果链。第四篇拆为上下两册，单独承载文案与脚本这一最高杠杆环节。

| 篇 | 标题 | 主要回答 | 字数 | 关键素材源 |
|---|---|---|---|---|
| 序言 | 写在前面 | 这本书要解决什么 | 3,000 | 两人前言 |
| 第一篇 | 底层逻辑 | 凭什么能做成 | 18,000 | 鹤·05-09、训·第一天、薛·1-2 |

| 第三篇 | 选题与素材库 | 拍什么 / 灵感从哪来 | 18,000 | 鹤·39、训·第二天、薛·02-06 |
| 第四篇·上 | 文案与通用结构 | 怎么把人留下来 | 18,000 | 鹤·40-41、训·第二天、薛·7 |
| 第四篇·下 | 四型脚本 | 不同目标用什么脚本 | 22,000 | 薛·8-15、薛·04-07 |
| 第五篇 | 拍摄·剪辑·表现力 | 怎么把脚本变成视频 | 18,000 | 鹤·16/32-38、薛·08-21 |
| 第六篇 | 增长·算法·投放 | 怎么让视频被看到 | 18,000 | 鹤·25-31/45、薛·10/23-24 |

**写作顺序建议：** 第一篇 → 第二篇 → 第三篇 → 第四篇·上 → 第四篇·下 → 第五篇 → 第六篇 → 第七篇 → 附录 → 序言（最后写）→ 番外卷（与正卷并行或之后单独启动）。

## 五、写作工序（Per-Chapter SOP）

每写一章按以下 6 步执行：

- [ ] **Step 1：定位本章在全书中的作用**——20 分钟。回答三问：上一章建立了什么？本章新增什么能力？下一章会用到本章哪个工具？
- [ ] **Step 2：精读素材出处**——按章节头部的 `素材出处` 字段，把所有引用文件**完整读一遍**。在 scratch 文件里逐条记录金句、案例、数据。
- [ ] **Step 3：列大纲**——本章按"现象 → 反共识结论 → 推导 → 案例 → 工具"五段式，每段先列 3-5 个小标题。
- [ ] **Step 4：写正文**——一次一段，每段写完不回头改。**遇到两位老师立场冲突时，直接按第九节"已融合立场清单"输出统一答案，不在正文展示分歧。**
- [ ] **Step 5：补工具**——确保章节末尾必出至少 1 个可填表格 / 检查清单 / 流程图。表格给"示例填好版 + 空白版"两个版本。
- [ ] **Step 6：自审 + commit**——按下面自审清单走一遍，然后 `git add` 单文件、`git commit -m "book: 写完 <章节文件名>"`。

**单章自审清单：**

- [ ] 所有引用案例都能在素材出处找到原文，没有编造
- [ ] 所有数据都和原素材一致（董宇辉 6 元玉米、立扬 0→22.8 万赞等具体数字）

- [ ] **检查是否无意中暴露了"两派分歧"——如有，按第九节统一立场重写**

## 六、质量标准

### 6.1 内容质量

- 每一节必须能让读者读完做出一个具体动作。一节读完读者不知道接下来做什么 → 不合格
- 每一篇必须有可印的输出物（练习章承担）
- 反共识结论 ≥ 全书 25 节

### 6.2 案例质量

- 案例必须真实可查，标注 `[素材出处]`
- 高频金案例配额管理：每个案例最多在 2 章中出现
- 每篇至少 1 个"5 个粉丝开单""7 天涨粉 1 万"这种小账号案例

### 6.3 工具质量

- 工具必须可填——"示范行 + 空白行"两版本
- 工具必须独立——能从书里撕下来单独用
- 工具必须有失败案例——每张表格附 1 个"这样填会出问题"的反例

### 6.4 风格质量

- 不用"宝子们""姐妹们""家人们"等场域化称呼
- 不用"颠覆认知""重新定义""内卷"等空洞词
- 不用"！！！"、连续问号、夸张副词（"巨爽""绝绝子"）
- 引用素材原话用 `> 引用` 块，保留原说话人口吻

## 九、已融合立场清单（写作时直接使用这一列，不再展示分歧）

| 冲突点 | 已融合立场（统一答案） | 使用章节 |
|---|---|---|
| 完播率重要性 | **完播时长 + 完播率组合看，完播时长是核心**；单一数字会误导 | 6.2 |
| 视频长短 | **在信息密度足够的前提下，越长越好**——"短"指密度高，不指时间短 | 4U.0、4U.1、6.2 |
| 垂直度 | **目的垂直 + 手段多维**——账号要解决一类问题（目的层垂直），但用多种内容形式呈现（执行层多维） | 2.3、6.3 |
| 投流时机 | **按投放目的分别决策**：商品推广 ROI > 0 即投；粉丝量投放看 CPC 与人群匹配；点赞型投放有边际效益递减，火了之后投点赞性价比急剧下降 | 6.8 |
| 原生感与包装 | **优先原生**——实体老板、原产地、专业行业都用原生场景；只有跨界跳行业时（如设计师卖女装）可适度包装人设 | 2.3、5.3 |
| 器材重要性 | **画质音质优先，器材按预算配**——用手机起步不丢人，但到一定阶段必须升级；不要在器材上死磕，但也不要拒绝合理升级 | 5.0、5.4 |
| 行业聚焦度 | **正卷讲通用方法论，番外讲行业落地**——读者按"先方法后行业"的顺序读 | 全书结构 |
| 干货 vs 拖时间 | **信息密度优先**——既不是堆干货也不是注水，而是每 5 秒都有用户没预期到的信息点 | 4U.1 |

**冲突处理总原则：** 写作时把以上"已融合立场"当作客观结论直接输出，**不要写"鹤老师说X，薛辉说Y"**。读者不应该感受到这是一本对照课程笔记。

## 十、执行方式

**两种执行选项：**

**1. Subagent-Driven（推荐）** —— 每章派一个独立子代理，参照本计划的章节小节，写完后审核再开下一章。优点：每章上下文干净；缺点：每章 30-60 分钟。

**2. Inline Execution（连写）** —— 在当前会话按本计划顺序逐章写。优点：可即时校准；缺点：会话长后容易丢失早期章节细节。
